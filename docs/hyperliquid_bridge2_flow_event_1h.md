# Hyperliquid 官方 Arbitrum Bridge2 USDC 存入 / 提出 1h 突发 → 8 币永续篮子（研究记录，先验否决；非先验净流入格弱观察）

## 短线：Hyperliquid 官方 Arbitrum 存款桥 Bridge2 USDC 存入 / 提出 1h 突发 → 8 币永续篮子（2026-11-21，先验否决；非先验净流入格仅弱观察）

- 背景：Liquity 节 / Tornado 之后「下一轮（短线）」所列。机制 = 链上永续 DEX 保证金新钱进出（投机杠杆资金入场 / 撤离）；不是已否决的 Arbitrum 官方桥 ETH 净流（长线、L1↔L2）、稳定币供给 / 铸赎、Curve 3pool、WETH9、Tornado、EigenLayer、Aave 清算、交易所资金费 / OI / 清算 / 主动买卖。本地文档、output 中此前 Hyperliquid 仅出现在上节「下一轮」提议里，不是重复。
- 数据（全部官方链上，`output/hyperliquid_bridge2_official_1h.csv`）：Hyperliquid 官方文档 hyperliquid.gitbook.io `for-developers/api/bridge2`（现标为 Legacy Bridge，CCTP 为首选）列出的 Bridge2 `0x2Df1c51E09aECF9cacB7bc98cB1742757f163dF7`，源码 github hyperliquid-dex/contracts `Bridge2.sol`；链上 `usdcToken()` = 原生 USDC `0xaf88d065e77c8cC2239327C5EDb3A432268e5831`（6 位小数）；代码首次出现区块 155,689,071（2023-12-01 UTC），60M–155M 区块无任何 USDC 转入。序列 = USDC `Transfer` to Bridge2（存入，含 `batchedDepositWithPermit` 的 transferFrom）/ from Bridge2（验证者完成的提款）；剔除 23 笔 Bridge2→Bridge2 自转（两边各算一次、净 0，合计 1.85 万 USDC）。公共 RPC tenderly `eth_getLogs` 全量重建区块 155,000,000–526,268,365，4M 块分片检查点 `scratch/hlbridge1h/ck/`。注：arb1.arbitrum.io 的 eth_getLogs 返回 `blockTimestamp=0x0`，第一遍有 38 个分片受影响，已整段删除并只用 tenderly 重拉（脚本对 0 时间戳直接报错）。
  - 7,204,083 条转账 = 4,116,879 笔存入 + 3,087,204 笔提出。**完整性**：终点块 `balanceOf(Bridge2)` = Σ存入 − Σ提出 **差 0 单位**（76,972,535.488563 USDC）；随机 12 小时用 arb1.arbitrum.io 按时间二分区块独立重拉 **12/12 一致**（笔数与金额）。
  - 完整 UTC 小时 **2023-12-02 01:00 → 2026-11-21 13:00 共 26,053 小时，0 缺口，不补值**（无事件小时为真实 0：仅上线首月 305 个零存款小时，之后 0 个；当前未完成小时丢弃）。
  - **充足性检查（先于任何 PnL）通过**：post（≥2026-03-05）6,278 小时、603,210 笔存入、每小时存入笔数中位 72、0 个零存款小时；提出 675,123 笔、中位 83。CCTP 迁移后流量确实下滑（存入额月度 2025-08 峰值 82 亿 → 2026-07 起 7–11 亿 USDC，2026-06 单月提出 39.5 亿 = 迁出），但仍远超 1h 测试所需。
  - 时滞：小时 h 的链上值在 h 收盘后才用，h+1 根 1h 永续开盘入场。
- 公式（`scratch/hlbridge1h/PRE_REGISTER.csv` sha256 `d055231f…6d086f7e`，看任何 PnL 前、拉数尚未完成时锁定 192 格；副本 `output/research_hyperliquid_bridge2_flow_event_1h_prereg.csv`）：
  - 序列：log_dep_usd = log1p(本小时存入 USDC)；log_n_dep = log1p(本小时存入笔数)；log_wd_usd = log1p(本小时提出 USDC)；net_musd = (存入 − 提出) 百万 USDC（原值带符号，高侧 = 净流入突发）。
  - z：W = 168h 滚动均值 / 标准差截至 t−1（min 84）；L=1 时 z=(x−μ)/σ，L>1 时 z=(Σ_L x − Lμ)/(σ√L)；z ≥ k 触发，下一根 1h 开盘入场，持有 H，不重叠。
  - 网格：4 序列 × L{1,4,8} × k{3,4} × 方向{long, short} × H{6,12,24,48} = 192 格（只做高侧突发）。存入 / 净流：long = 顺势（新保证金 = 风险偏好），short = 逆势；提出：short = 顺势（去杠杆），long = 逆势。
  - **唯一先验 `log_dep_usd_L4_k3_high_long_H24`**；回退 `log_wd_usd_L4_k3_high_short_H24`。
  - harness 与 tornado1h / curve3pool1h 相同：OKX d8 深历史 1h（train 2023-12-05（数据起点 + 84h 预热）→2024-10-21 = 深未见；test →2026-03-05；post →末尾）、Gate d8 官方 1h（test 部分 + post + gate_window 2025-09-28→）、未调参 OKX new8（LINK LTC DOT TRX BCH ATOM NEAR UNI）；真实永续 taker 5.1 bps/边（不假设 maker 2 bps），压力 15.1 bps/边；官方资金费；±720h 时移安慰剂（OKX + Gate）；额外 ±168/±336/±2160h 时移、168h 整块打乱（20 个种子）安慰剂与邻域（k 2.5/3.5、W 336/720、L 2/6、H 18/36）；同脚本逐小时基线（同方向同 H）。
- 结果（真实费，每笔篮子净 bps）：
  - 192 格中 18 格 8/8，其中 **12 格可用 8/8，全部是 long**（net_musd 9 格、log_n_dep 3 格）。方向不对称很大：所有 long 格 OKX 平均 train +64.6 / test +32.3 / post +34.3，short 格 −85.0 / −52.7 / −54.7；而同脚本逐小时 long 基线为负（H24：−4.7 / −5.6 / −19.6），即「流入突发后做多」的优势不是篮子 beta。
  - **先验** log_dep_usd L4 k3 long H24：5/8。OKX train +75.8（t 1.36，n 43）/ test +18.9（t 0.41，n 86）/ post **−2.8**（t −0.04，n 27，中位 +8）；Gate post −1.6、gate_window −67.0；new8 +54.4 / +30.4 / +28.5；压力费 OKX +55.8 / −1.1 / −22.8。post 逐月：事件均值 > 基线 4/9、月和 >0 3/9（两所相同）。安慰剂 −720h post +82.9、+168h +62.7 均优于先验；块打乱 post 均值 −3.2，先验处于中位（frac≥ 0.5）。邻域乱：k3.5 post +87.5、k2.5 −11.2、W336 −30.6、L6 −14.7、L2 +30.9。
  - **回退** log_wd_usd L4 k3 short H24：5/8。OKX train **−106.2**（t −1.82，n 41，劣于基线 −15.7）/ test −9.4（n 75）/ post +37.1（t 0.60，n 36）；Gate post +36.3；post 逐月 6/9（两所）；块打乱 frac≥ 0.15；深未见大幅为负。
  - **非先验、事后挑出的最佳格（仅探索）** net_musd L1 k4 long H24：8/8。OKX train +64.4（t 1.07，n 43，**中位 −0.0**）/ test +49.5（t 1.04，n 60）/ post **+135.6（t 2.77，n 24，中位 +77，胜率 71%）**；Gate post +136.3（t 2.78），但 **Gate test 只有 +1.3（n 16，中位 −97）**；new8 +83.7 / +51.9 / +107.6；压力费 OKX +44 / +30 / +116、Gate post +116。post 逐月：事件均值 > 基线 **8/9**、月和 >0 **8/9**（两所相同，6 月无触发）。安慰剂全部低于它：±168/±336/±720/±2160h post 在 −72 ~ +32；168h 块打乱 20 个种子 post 无一 ≥ 实际（均值 −17.7，p90 +22.3）。邻域稳定为正：k2.5 +26.8、k3.5 +81.4、W336 +103.4、W720 +83.8、L2 +151.4、L6 +223.6、H18 +70.1、H36 +92.4（post）。但它是 192 格里按 post 事后挑出的（post t ≥ 2 的只有 3 格），深未见 t 仅 1.07 且中位 ≈ 0、Gate 可用的未见段（test）不成立 ——「在未见段 + post 两所都成立」这一条不满足。
- 结论：**先验否决**（post 为负、劣于安慰剂、邻域乱；回退深未见大幅为负）。非先验 net_musd L1 k4 long H24（净流入突发 → 做多 24h）记为 **弱观察**，不是强观察、不实施：只靠 post 段 24 笔，深未见与 Gate 未见段都不显著，且为事后挑选。不改默认、不动纸面盘、不改代码。已启动官方实时记录器 `scratch/hlbridge1h/record.py`（只追加新完成小时），用前向样本复核：若 2026-11-22 之后前向 ≥ 20 笔仍保持 OKX + Gate 均值 > +40 bps、中位 > 0，再按新预注册单独复审。**勿以改 L / k / H / W / 方向、换序列（存入额 / 笔数 / 提出 / 净流 / 唯一地址 / 大额存款）、改用 CCTP 或 HyperEVM 流量、或换其他永续 DEX 桥的方式在现有历史上重测先验；净流入格只能用前向数据复核。**
