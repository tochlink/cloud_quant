# 官方周度现金囤积（H.6 零售货基 / H.8 银行存款）4h 入场闸门（否决）

## 长线新族：官方周度「现金囤积」——美联储 H.6 周度零售货币基金（WRMFNS，ICI 采集）与 H.8 商业银行存款（DPSACBW027SBOG）周变化 z / 趋势 → 4h 默认书入场闸门（2026-11-21 ~00:46 PST，研究，不改默认；否决）

- 查重：文档 / `output/research_*.csv`（约 1,033 个）/ 记忆中无货币基金、MMF、ICI、H.8、银行存款条目。最近的已否决族：M2SL 月度水平 / 增速体制（2026-11-14）、联储净流动性（WALCL − TGA − RRP）、SOFR − IORB、稳定币供给增速 / 冲击。本轮看的是**周度**资金流冲击（1 周 / 4 周对数变化的 z）与水平对均线，机制不同，继续。
- 可行性：ICI 官网周报只免费给**最近 20 周**（ici.org 说明底层历史仅会员 / 订阅；盒子直连 ici.org 返回 403），无法回测 → 不用。改用联储官方 H.6 周度零售货基 `WRMFNS`（周一截止，数据由 ICI 采集，联储发布；FRED / ALFRED 官方镜像，1980-02 → 2026-10-05，2,436 周，0 缺口）。机构货基周度 `WIMFNS` 2021-02 已停发。H.8 `DPSACBW027SBOG`（全部商业银行存款，季调，周三截止，1973-01 → 2026-11-11，2,811 周，0 缺口）。官方周表 `output/mmf_h8_official_weekly.csv`（不入库）。
- 时滞（保守，不补缺、不插值）：H.6 自 2021-02-23 起改为**月度**发布，周度数据随月报一次性给出。逐个探测 `federalreserve.gov/releases/h6/YYYYMMDD/` 找到 75 个发布日，再用 ALFRED 在每个发布日的 vintage 判定每一周**首次出现**的日期 R，可用时刻 = R + 1 天 00:00 UTC（观测到可用 11–51 天，中位 37 天）。H.8 官方周五 16:15 ET 发布周三 W 的数据（W+9；ALFRED 抽查 2026-11-11 首见于 2026-11-20 vintage，节假日周为 W+8 / W+9），保守取 W + 13 天 00:00 UTC。
- 修订偏差：只用当前 vintage 值。WRMFNS 在 2026-07-28 的 H.6 中被重新定义 / 基准修订，当前值比首发值高约 32%；但同一份月报内部的周变化，当前值与首发值相关 0.988，所以用对数变化 / z 基本不受水平断点影响。H.8 季调值每年基准修订，同样只有当前 vintage，回测偏乐观。
- 公式（看 PnL 前锁定 `scratch/mmfh8_4h/PRE_REGISTER.json`，sha256 00878757…0a84，96 格）：取对数水平；`d1z` = 1 周对数变化对过去 N 周（26 / 52 / 104）的 z > k（1 / 2）；`d4z` = 4 周对数变化对 52 周的 z > k（1 / 2）；`trend` = 对数水平 > SMA(N 周)（13 / 26 / 52 / 104）。旗标先按观测顺序算，再挂到可用时刻（每次发布取当时已知的最新一周），前向填充到 4h 棒。2 序列（rmf / dep）× 12 形式 × 4 侧（long_off / short_off / both / contra_both，只拦新开仓，已有同向仓保留）。**唯一先验**：货基 4 周增速激增 = 现金囤积 = risk-off → 拦新多，`rmf_d4z_n52_gt1_long_off`；回退 `rmf_d1z_n52_gt2_long_off`。锁定前看过旗标占比（非 PnL），先验未因此改动。
- 交易与评价（同 gpr4h / kwtp4h 模板，同脚本基线）：官方 OKX / Gate 4h 现货 + 永续、官方资金费；OKX d8（2023-02-01 起）、Gate d8（2022-07-01 起）、OKX d7_noBNB（2022-04-01 起）× deep_unseen（→ 2024-10-21）/ tune_pre（→ 2026-03-05）/ post（→ 2026-11-14）= 9 段日 Sharpe；真实费率现货 10 / 永续 taker 5.1（maker 2）bps，压力 20 / 15.1；安慰剂平移 ±7 / ±14 / +180 / −120 / +365 / −119 天；邻域；未调参 new8（LINK/LTC/DOT/TRX/BCH/ATOM/NEAR/UNI，两所最近 4500 根，2024-11-26 起）。

- 结论：**否决**，不实现、不进观察名单、不改默认、无代码改动，仅文档。H.6 月度发布导致周度冲击要晚 3–7 周才能用，2026-03 后货基增速平稳，闸门基本不触发；能触发的 2022–2026-03 段，先验在 tune 段输、平移安慰剂更好；H.8 存款没有稳定方向。勿以同一机制换 N / k / 方向、换 1 周↔4 周变化或水平均线、换零售 / 机构 / 政府 / 优先型货基、换 H.8 其他科目（大额定期存款、其他存款、贷款）、换 H.6 M1 / M2 周度、或改用 ICI 20 周快照 / OFR MMF 月度再测。
