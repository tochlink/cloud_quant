# OKX official Proof of Reserves user liabilities → 4h default-book entry gate (2026-11-21, research, REJECTED)

- **Data (official only)**: `https://www.okx.com/v2/asset/audit/history`, the JSON backend that okx.com/proof-of-reserves and /proof-of-reserves/download use (the endpoint was found in the page's JS bundle; the page SSR only lists 7 audits). Field `liabilityBalances` = "OKX account assets" (user liabilities) per coin. 49 snapshots, 2022-11-22 → 2026-10-31 UTC (audit IDs, BTC/ETH/USDT/USDC liabilities and reserves saved in `output/okx_por_official_snapshots.csv`). USDC is not in PoR before 2023-04-22: treated as absent, not zero. No third-party source, no fill.
- **Publication lag**: the snapshot time is not when it was published. A snapshot becomes usable at the next UTC 00:00 after the HTTP `Last-Modified` of OKX's per-audit merkle file `static.okx.com/cdn/okx/por/merkel/por_{auditId}_proof_data.zip`. Observed lag from snapshot to upload: 1.6–14.8 d, median 5.3 d. The first 5 snapshots (2022-11..2023-03) have no such file (404), so they use snapshot + 16 d (the max observed lag rounded up, plus 1 d), next UTC 00:00. Values are ffilled onto 4h bars.
- **Formula**: series stable_liab = USDT + USDC (each comparison uses only coins present in every snapshot involved), btc_liab, eth_liab (coin units). Flag forms: chg1 (v_i − v_{i−1} > 0), chg3 (v_i − v_{i−3} > 0), lvl6 (v_i > mean of previous 6). Sides: long_off / short_off / both / contra_both / cap_short_off. The gate only blocks NEW entries: existing positions, exits and stops are untouched, and a NaN flag means no block. Grid: 3×3×5 = 45 cells, pre-registered before any PnL (sha256 `df73ed940492e817596e942b4446856d3e3653ad874dd2b4130a28a17ecafd0c`). Prior: stable_liab_chg1_cap_short_off. Fallback: stable_liab_chg3_cap_short_off.
- **Validation**: official OKX d8 / Gate d8 / OKX d7_noBNB 4h with the same-script baseline (default MA 50/150). Real fees are taker 5.1 / maker 2 bps plus official funding; the stress case uses perp taker 15.1 bps. 9 Sharpe slices: deep unseen [2023-06-01, 2024-10-21), tune [2024-10-21, 2026-03-05), post [2026-03-05, 2026-11-14). **The deep slice is short (~17 months) because PoR only starts in 2022-11.** Also run: untuned new8 coins, snapshot-shift placebos ±1/±3, and snapshot-shuffle placebos (seeds 1–3).

- Stress at 15.1 bps: prior post OKX 28.5 vs 55.9, Gate 29.0 vs 56.8. Best non-prior post 71.0 / 71.7.
- New8 untuned (last 4500 bars, post): prior OKX +1.2 vs +3.3, Gate +14.3 vs +16.4. Fallback −5.5 / −6.0. stable_liab_chg3_short_off +14.5 / +28.9 but pre worse (47.6 vs 60.3, 45.8 vs 57.1).
- **Why it is rejected**: both pre-registered cells lose badly on deep unseen and post. The only ≥6/9 cells (chg3_short_off / chg3_both / chg1_long_off) are non-prior. chg3_short_off points the opposite way from the economic prior (it blocks shorts when stablecoin liabilities are *falling*). It has no deep-unseen edge (flag ≈1 for 94% of deep, so it almost never acts), and its post months are only 5/2 (below the 6/9 bar). Its post edge comes from the 2026 fall in USDT liabilities (10.2B → 8.0B), which kept the flag at 0 and so blocked new shorts. A stale placebo (fallback shifted +3 snapshots) beats it in post, so the edge is not specific to the signal.
- **Verdict**: REJECTED. No default change, no paper change, no shadow, no code change.
- **Never retest**: do not retest OKX PoR liabilities (or reserves / reserve ratio) as a gate by changing form, window or side, by swapping coins (BTC/ETH/USDT/USDC/other), by using reserves or the reserve−liability gap, or by switching to another exchange's PoR (Binance/Bybit/Bitget).
