- 查重：文档 / `output/research_*.csv` / 记忆中已测的止损族有静态 ATR 倍数 1.5/2.5/3、按波动分位缩放倍数、按效率比缩放、随持仓时间收紧、入场后宽限期、保本 / 锁利 / 吊灯 / 回吐 / 盘中 MFE 回吐；没有「用策略自己历史赢单的最大不利波动（MAE）分布在运行时学习止损倍数」的条目（MAE 仅出现在事件明细描述里）。这是 kean 要的「参数在运行时按自身盈亏自动适配」的一种。
- 公式（`scratch/maestop4h/PRE_REGISTER.json`，sha256 `30e81efd957b38a0f663777f1211a63df85eef48e0256830dc44d7cfe8309334`，06:53 PST 在任何 PnL 前锁定）：
  - 影子信号段（不受止损 / 闸门截断，避免「止损本身截断 MAE → 倍数自我收缩」）：每币合成信号 `SIG[a..b]=d≠0` 为一段，入场 = 永续 open[a+1]，持有 a+1..b+1，离场 = open[b+2]；
    `MAE_ATR = max(0, max_k d·(open[a+1] − (d>0 ? low_k : high_k)) / ATR14[a])`；赢单 = `d·(open[b+2] − open[a+1]) > 0`。
  - 第 i 根新开仓时，取全书（8 币、多空合并）已在 i−1 前完成的最近 W 个赢单段：`m = clip(Q_q(MAE_ATR) + buf, 1.25, 4.0)`；不足 15 个赢单 → m = 2（默认）。初始止损 = 入场 ∓ m × ATR14[i−1]；`size()` 不变（风险 5% / 权重 20%，大多数仓位受权重上限约束，所以主要只改变出场）；`rebalance_mode=stop` 按该笔自身止损调仓。
  - 网格 q{0.7, 0.8, 0.9} × W{30, 90} × buf{0, 0.25} = 12 格；先验 q0.8 W90 buf0；后备 q0.9 W30 buf0；邻域 q0.75/0.85、W60/120；对照 = 固定 m = 先验实际 m 的中位数；安慰剂 = MAE 池滞后 2190 根（1 年）、从先验实际 m 中随机抽（种子 1/2/3）；压力费 20/15.1 bps。
