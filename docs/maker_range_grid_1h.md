# 短线：永续双向挂单区间网格（maker 网格机器人）1h（2026-11-21，否决）

- 族：每个币在固定时段内围绕开盘价挂双向限价网格，买单成交后在上一格挂止盈卖单，卖单同理，赚格距减 maker 费。之前只测过 maker 限价入场 / 止损单类型 / 配对价差 / 均值回归支线，没有测过网格做市本身。
- 预注册：scratch/grid1h/PRE_REGISTER.json（sha256 b245aa82…），32 格，看收益前锁定。先验 `V0.5_N6_T24_ER`，备选 `F1_N3_T24_none`。
- 数据：OKX 官方 1h 永续 2022-01-29→2026-11-20（默认 8 币 + 未调参 new8），Gate 官方 1h 永续 2025-09-24→2026-11-20；官方资金费；OKX 官方 5m（2025-01-10→2026-11-13）用于检验 1h 成交假设。
- 公式：时段 T∈{24,72}h 从 UTC 0 点起，中心 c0=首根开盘。买格 L_j=c0(1−j·s)，止盈 c0(1−(j−1)s)；卖格 U_j=c0(1+j·s)，止盈 c0(1+(j−1)s)，j=1..N，N∈{3,6}，每格名义 = 该币资金的 1/N。格距 s∈{1%, 2%, 0.5×σ20, 1.0×σ20}（σ20 = 前 20 日日对数收益标准差）。过滤∈{无, ER7<0.3}（7 日效率比，开盘时已知）。
- 成交（保守）：价格需穿过挂单价 5 bps 才算成交，按挂单价成交；入场当根不止盈；收盘越出 c0(1±(N+1)s) 下一根开盘吃单全平并停到时段结束；时段结束下一开盘吃单全平。费用 maker 2 bps / taker 5.1 bps，压力 15.1 bps；持仓按官方资金费结算。8 币各 1/8 资金，日度求和。
- 8 项检验：OKX 2026-03 后收益>0 且 Sharpe≥0.5；Gate 2026-03 后>0；OKX 深未见（2022-01→2024-10-21）>0；OKX 调参段>0；new8 2026-03 后>0；new8 深未见>0；压力费率 2026-03 后>0；2026-03 后正收益月 OKX≥6/9、Gate≥5。
