## 数据（官方，未编造、未回补）
- 韩国关税厅（관세청）通关口径的月度出口 / 进口，取自韩国银行 ECOS 官方镜像，统计表 `901Y118`（3.2.1 수출입 총괄，数据来源标注为 관세청），项目 `T002` 出口额 / `T004` 进口额，单位千美元。
- API：`https://ecos.bok.or.kr/api/StatisticSearch/sample/json/kr/1/10/901Y118/M/{起}/{止}/{T002|T004}`，覆盖 2000-01 → 2026-09，共 321 个月，无缺失。本地文件 `output/kr_customs_trade_official_monthly.csv`。
- 关税厅前 10 天 / 前 20 天的速报：没有找到官方的机器可读历史，所以不用，也不回补。
- 发布时滞：月份 M 的数据只在 **M+1 月 16 日 00:00 UTC** 之后使用（关税厅约在 M+1 月 15 日韩国时间公布确定值；产业通商资源部 1 日的速报更早，所以这个时滞是保守的）。数据前向填充到 4h K 线，没有前视。

## 公式与预注册（看 PnL 之前锁定，`scratch/krexp4h/PRE_REGISTER.json`，2026-11-22 21:20 PST）
- 三个序列：`yoy` 出口同比 %；`yoy3` 3 个月合计出口同比 %；`bal` 3 个月合计贸易差额（出口 − 进口）。
- 八种形式：`lvl0` 序列 > 0；`chgN` 序列 − N 个月前 > 0，N ∈ {1, 3, 6}；`trendN` 序列 > SMA(N 个月)，N ∈ {6, 12}；`z60gtK` (序列 − SMA60) / STD60 > K，K ∈ {0.5, 1}。
- 五种侧：long_off / short_off / both / contra_both / cap_short_off。闸门只拦新开仓，已有的同向仓位保留。
- 合计 3 × 8 × 5 = 120 格，加同脚本基线（默认 #1 ma_trend MA50/150，不加闸门）。
- 经济先验（锁定后不翻转）：出口上行或顺差 = 全球贸易上行 = risk-on → cap_short_off / contra_both。回退先验格是 `yoy_lvl0_cap_short_off`。
- 验证：官方 OKX d8（2023-02 起）、Gate d8（2022-07 起）、OKX d7_noBNB（2022-04 起）的 4h 永续数据；真实费率（永续 maker 0.02% / taker 0.051%），另跑压力费（spot taker 20 bps / perp taker 15.1 bps）。
- 分段：深度未见期（起点 → 2024-10-21）、调参期（→ 2026-03-05）、post（2026-03-05 → 2026-11-14）。按 9 片 Sharpe 胜场计分，并统计 post 月份胜负、邻域，以及 ±7 / ±14 / +180 / −120 / +365 / −119 天的日历平移安慰剂。

## 结果（`output/research_kr_customs_exports_gate_4h.csv`）
- 基线：
  - OKX d8：深度 +35.14% / Sharpe 0.71，调参 +85.08% / 1.47，post +59.90% / 2.23。
  - Gate d8：深度 −3.63% / 0.09，调参 +84.25% / 1.46，post +60.32% / 2.25。
  - OKX d7_noBNB：深度 +54.92% / 0.75，调参 +92.93% / 1.56，post +50.76% / 2.10。
- 120 格的胜场分布：0 胜 46 格，1 胜 20，2 胜 8，3 胜 32，4 胜 5，5 胜 2，6 胜 7。没有任何一格达到 7/9 或更高。
- 2026 年出口暴涨（2026-09 同比约 +84%），post 期几乎所有出口闸门都一直处于"开"的状态，所以：
  - 先验最佳 `bal_z60gt1_cap_short_off` 6/9：post 期把所有新空单都拦掉了，OKX 只有 +13.43% / 1.07（基线 +59.90% / 2.23），Gate +13.74% / 1.09（基线 +60.32% / 2.25），d7 +7.54% / 0.75，月份 5 好 / 4 差。+7 天安慰剂同样 6/9，post 完全相同 → 没有时点特异性。
  - 回退先验 `yoy_lvl0_cap_short_off` 3/9：post 同样崩到 +13.43% / +13.74%。
  - 6/9 的其余格都是非先验的 `*_short_off`（bal_trend12 / bal_chg6 / bal_trend6 / bal_chg1 / yoy_chg6 / yoy_trend12）。它们在 post 期几乎不触发，post 与基线一致，月份 0/0 或 1/0，增益全部在 2026-03 之前，没法做样本外验证。bal_trend 邻域里 trend3 / trend4 / trend18 只有 5/9、4/9、4/9。
- 压力费下结论不变：bal_trend12_short_off 的 post 与压力费基线相同（OKX +55.94% / 2.12）。
- 预注册里的 M+2 时滞稳健性检查和 untuned new8 没有跑，因为先验格和回退格都在 post 阶段就已经失败。

## 结论
**否决**。不改代码、不改默认、不加模拟盘。
