## 长线新族：SNB 活期存款（sight deposits，总额 TG / 境内银行 GI）作为 4h 默认书入场闸门（2026-11-22 ~10:39 PST，研究，不改默认；否决）

- 查重：`docs/STRATEGY_FORMULAS.md`、`docs/*.md`（86 个）、`output/research_*.csv` 与记忆检索 SNB / sight deposits / Swiss National / 瑞士央行 / 活期存款：唯一命中是 1h「非美央行决议」事件族的勿重测条款里把 SNB 决议列为排除事件集（政策利率决议时点），**活期存款作为流动性闸门从未测过**。也不是已否决的 HKMA 总结余 / HIBOR（`docs/hkma_interbank_liquidity_gate_4h.md`，2026-11-22 否决）、美国 Fed 净流动性 / H.4.1 / H.8 / TGA / ON RRP / SRF / SOFR−IORB / M2、美元指数、日元 / 人民币汇率趋势、JGB 收益率等族；本族是瑞郎央行准备金（SNB 买外汇 → 活期存款增加；卖外汇 / 发 SNB Bills / 回购回收 → 减少）。
- 机制：活期存款 = 瑞郎基础流动性；扩张 = SNB 压制瑞郎升值 / 欧洲避险流动性充裕；收缩（2022 起抛外汇、SNB Bills）= 流动性回收、risk-off。先验：收缩时拦新多。只拦新开仓，已有持仓、止损、离场不变。默认 4h 书（#1 双均线 50/150，8 币永续）。
- 数据（只用官方，不编造、不回补）：SNB 官方数据门户 `https://data.snb.ch/api/cube/snbgwdchfsgw/data/json/en`（cube `snbgwdchfsgw`，单位瑞郎百万）：`GI` 境内银行活期存款（2009-01-09 起）、`UEB` 其他活期负债、`TG` 活期存款总额（2011-08-19 起）；全部为周五口径，932 周、**0 个缺周**，最新 2026-11-13（edition 2026-11-16 10:00 苏黎世）：总额 443,728、境内银行 425,271、其他 18,457（百万瑞郎）；总额 4 周 −13,287、13 周 −15,026。研究用 2018-01-05 起 463 周。存 `output/snb_sight_deposits_official_weekly.csv`（不入库），原始 JSON/CSV 在 `scratch/snbsight4h/raw/`。
