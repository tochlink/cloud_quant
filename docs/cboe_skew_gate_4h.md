# 长线：CBOE SKEW 指数（标普 500 期权隐含尾部风险）作为 4h 默认书入场闸门（2026-11-21，否决）

- 查重：文档、output/research_*.csv、记忆中没有 SKEW 指数条目。之前只用过 VIX 收盘水平（VIXCLS，FRED 宏观闸门），以及加密资产自身收益偏度（skew_follow / skew_contra）。SKEW 衡量的是标普期权的尾部定价，属于不同的信息源。
- 数据：CBOE 官方 cdn.cboe.com SKEW_History.csv，1990-01-02→2026-11-20，当前版本。美国交易日 D 的收盘值从 D+1 04:00 UTC 起才算已知。默认书用官方 OKX / Gate 4h 数据，通过 qtw 回测（真实费率加官方资金费）。
- 公式：flag=1 表示尾部风险定价偏高。hi_n：SKEW_D > 最近 n 个观测的均值（含 D），n∈{20,60,120,250}；chg_n：SKEW_D > SKEW_{D−n}，n∈{5,20}。方向 5 种（long_off / short_off / both / contra_both / cap_short_off），只拦新开仓，同向续持不拦。共 30 格，看收益前锁定（scratch/skew4h/PRE_REGISTER.json）。先验格 `skew_hi_n60_long_off`，备选格 `skew_hi_n120_long_off`。
- 区间：深未见 OKX 2023-02 / Gate 2022-07 / OKX d7 2022-04 → 2024-10-21；调参段 → 2026-03-05；2026-03 后 → 2026-11-14。安慰剂：时移 ±60 / ±250 个观测，加 2 次打乱。
