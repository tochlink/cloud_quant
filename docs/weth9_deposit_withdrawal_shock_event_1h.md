  - 合约 Ethereum 主网 `0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2`。官方事件 `Deposit(address,uint256)` 与 `Withdrawal(address,uint256)`（`wad` 为 wei）。WETH9 本身部署于 2017-12 / 2018-01；本轮官方扫描从第一个时间戳 ≥ 2022-01-01 00:00:00 UTC 的区块 13,916,166 起，因为更早没有官方 OKX / Gate 1h 永续书可测。扫描覆盖到合并时链上头块 26,460,143，其中分片窗口到 26,459,590，合并阶段用官方 `getLogs` 补了头块尾 26,459,591–26,460,143（553 块、6,997 笔，缺失 0）。主前缀 13,916,166–17,955,366、缺口 17,955,367–17,999,999、四个后段分片 18,000,000–26,459,590 均为单一连续前缀、missing=0，源之间无重叠块。

  - 研究用官方 1h 序列：42,840 根完整小时，2022-01-01 01:00 → 2026-11-21 00:00 UTC，日历缺口 0，有效小时 42,840，零成交 0，正成交 42,840，NaN 0。指标 `eth_dep` / `eth_wd` = 该 UTC 小时官方 `wad` 之和 / 1e18，再取 `log1p`。封闭小时合计官方事件 263,589,332 笔（Deposit 141,168,899 / Withdrawal 122,420,433）。中位数约 Deposit 5,452.31 ETH、Withdrawal 5,415.41 ETH。滞后：已收盘小时的下一根 1h 永续开盘才入场。
- 公式（预注册，144 格）：指标 `log_dep` / `log_wd`；回望 L = 1 / 4 / 8 小时；阈值 k = 3 / 4 / 5；方向 burst（只做突然偏高）或 twosided；mode = mom / contra；持有 H = 24 / 48 小时。z 窗 168 小时、至少 84 小时：L=1 为 `(x-μ)/σ`，L>1 为 `(sum_L x - Lμ) / (σ√L)`，μ / σ 用截至 t−1 的滚动窗。交易为 OKX 默认 8 币、没调过参的另外 8 币、以及 Gate 默认 8 币的官方 1h 永续，计入官方资金费；真实吃 5.1 bps（往返 2×taker），压力吃 15.1 bps。分段 train 2022-02-15→2024-10-21、test 2024-10-21→2026-03-05、post ≥2026-03-05，另报 Gate official 窗 2025-09-28 起。安慰剂把信号平移 ±720 小时。计分 8 段（OKX d8 train/test/post、OKX new8 train/test/post、Gate d8 post / gate_window）；可用 8/8 要求 8 段均值都为正，且 OKX d8 事件数 train≥10、test≥8、post≥8。经济先验（看结果前锁定，不翻转）：官方包装 / 拆包量突然偏高 = 链上 ETH 进出规范 WETH、DeFi 活跃 / 注意力脉冲 → risk-on，突发偏高后做多 8 币篮子（burst / mom）。contra 与 twosided 为预注册非先验探索。回退先验格：`log_dep_L1_k3_burst_mom_H48`。不在看结果之后把净流入或合计成交升为第三主指标，也不改用原始 ETH 数量。
- 结果：CSV 4,608 行（144 个预注册格 × 真实 / 压力费 × 真实 / ±720h 安慰剂）。**8 段全赚 10 格，其中样本够用的可用 8/8 只有 2 格，全部是非先验的 twosided + mom + H=48，没有一格是先验 burst。** 两个可用格以及其余全正低样本格的 OKX d8 post t 全部 < 1.5（可用格最大 0.21）。
  - 先验回退格 `log_dep` L=1、k=3、burst、mom、H=48 不是可用 8/8：OKX d8 train +33.24 bps / t=0.80 / n=126，test −25.82 / −0.37 / 52，post −20.32 / −0.25 / 29（命中率 0.414，中位数 −109.67）；Gate post −18.40。test / post 全部为多（burst）。先验不成立。
  - 按可用 8/8 里 OKX d8 post 均值最好的是 `log_dep` L=8、k=4、twosided、mom、H=48：OKX d8 train +123.20 bps / t=2.15 / n=99，test +174.15 / 2.06 / 41，post +23.01 / 0.21 / 18（中位数 −44.54，命中率 0.389，18 笔里 11 笔为多）；OKX new8 post +57.87 / 0.52 / 18；Gate post +24.45 / 0.22 / 18，gate_window +73.54 / 0.74 / 26。后段均值被少数赢家拉着略正，中位数已为负。压力费后 OKX d8 post 只剩 +3.01 / t=0.03，Gate post +4.45 / 0.04。
  - 另一个可用格 `log_wd` L=8 k=4 twosided mom H=48：OKX d8 train +84.50 / t=1.54 / n=93，test +230.33 / 2.39 / 41，post +16.67 / 0.14 / 16（中位数 −111.07，命中率 0.375，16 笔里 12 笔为多）；OKX new8 post +65.09 / 0.48 / 16；Gate post +17.71 / 0.14 / 16。压力费后 OKX d8 post −3.33 / t=−0.03，Gate post −2.29。train / test 好看，2026-03 之后塌掉。
  - 其余 8 个全正格都是 L=4 或 8、k=5、mom、H=48，post n 只有 5–6，达不到可用门槛；OKX d8 post t 最高 0.60。没有 contra 格进入全正 8/8。
  - 安慰剂：两个可用格的 ±720h 都复制不出 train / test 上那种 t≈2 的边。`log_dep` 锚点 +720h：train +23.4 / t=0.49，test +5.9 / 0.08，post −77.5 / −0.96；−720h：train −66.6 / −1.63，test +52.1 / 0.65，post +42.0 / 0.63。`log_wd` 锚点 +720h train 已为负，post −88.1 / −1.08。安慰剂没有做出可用 8/8，但也说明真实格子的前段边并不特殊到能在后段站住。
  - 邻域（同一 metric / side / mode = twosided mom H=48，只改预注册的 L / k，不升主榜）不稳。`log_dep` 9 个邻域格里只有锚点 L=8 k=4 可用；邻近 L=8 k=3 是 7/8 且 post 只有 +9.81 / t=0.17；L=8 k=5 全正但 post n=5；L=4 k=3 / k=4 与 L=1 各档 post 为负（例如 L=4 k=3 post −112.71 / t=−1.71 / n=41）。`log_wd` 同样只有锚点可用，邻近 L / k 的 post 多为负，L=4 k=5 虽全正但 post n=5。不是一整片稳定邻域。
  - 压力费：两个可用格在 15.1 bps 下 post 边基本消失（一个接近 0，一个翻负），挡不住 t 偏弱、后段中位数为负和邻域塌掉。
