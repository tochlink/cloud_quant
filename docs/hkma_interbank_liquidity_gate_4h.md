- 机制：港元银行间流动性 = 亚洲离岸资金面晴雨表（套息、南向 / IPO 资金、香港作为亚洲加密枢纽）。流动性宽松（总结余高 / 上升，HIBOR 低 / 下降）= risk-on → 允许开多；收紧 → 拦新多。只拦新开仓，已有持仓、止损、离场不变。默认 4h 书（#1 双均线 50/150，8 币永续）。
