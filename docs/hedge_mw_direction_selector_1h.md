# 短线：逐币在线 Hedge（乘法权重）方向选择器 1h —— 否决

研究时间：2026-11-23 约 05:08–05:20 PST（量化系统7x24打磨）。结论：**否决，仅文档；默认与纸面不变。**

## 想法
kean 希望策略能按实时盈亏“自己选方向”。本轮把这个想法做成一个可检验的短线机制：每个币有三个“专家”——
1h 趋势（TF）、1h 反转（MR）、空仓（CASH）。每个专家的**已实现净收益**（含真实费率和官方资金费）按指数衰减累计，
用 softmax（Hedge / 乘法权重算法）换成权重，权重高的专家决定方向。专家都在亏时，权重自动转向空仓。
此前做过的“跟随领先者 / 自适应参数 / 集成投票”都是 4h 均线参数层面的，没有做过 1h 逐币按盈亏的方向选择。

## 公式（PRE_REGISTER.json sha256 `e17854c408bffdbf94a0389e1a9c4f4296462a3ef41b715c13f8b191f086fb3f`，48 格，先锁后看）
- 专家：`eT = sign(C_t / C_{t−L} − 1)`，`eR = −sign(C_t / C_{t−S} − 1)`，`eC = 0`
- 专家逐根净收益 `g_e(t) = e(t−1)·r_t − e(t−1)·funding_t − fee·|Δe|`；到 t 收盘才知道，延后一根使用
- `G_e = Σ_k 2^{−k/H}·g_e(t−k)`（半衰期 H 小时），`w = softmax(η·G_T, η·G_R, 0)`
- 分数 `s = w_T·eT + w_R·eR`；滞回仓位：`s ≥ θ` 做多，`s ≤ −θ` 做空，`|s| < θ/2` 平仓；t 收盘出信号，t+1 开盘成交
- 8 币等权篮子（每币 1/8，1x），真实 taker 5.1 bps/边；另测 maker 2 bps、压力 15.1 bps
- 网格：L {24,72} × S {4,12} × H {72,168,336} × η {50,200} × θ {0.3,0.6}
- 先验 `L24_S4_H168_eta200_th0.3`；后备 `L72_S12_H336_eta50_th0.3`
- 同脚本基线：只用 TF、只用 MR（同一滞回），空仓 0，等权买入持有（参考）
- 安慰剂：用于计算权重的专家收益整体平移 +720h / +1440h

## 判定
预注册的 7 条全部失败（post 未超过 max(TF, MR, 0)；deep 为负；new8 为负；压力为负；先验未胜安慰剂；邻域 0/48）。**否决。**
根因：1h 符号类专家本身没有毛收益（maker 费下也大幅亏损），按盈亏加权只能在“亏得多”和“亏得少”之间选，选不出正收益。

**以后不要再测**：通过改 L、S、H、η、θ，换 softmax 为跟随领先者 / Thompson / EXP3，加更多 1h 符号类或均线类专家，
改成 15m 或换成单币，或换衡量盈亏的窗口，来重测“1h 逐币按已实现盈亏选方向”。只有专家本身已被单独证明有正净收益时，才值得在其上做方向选择。
