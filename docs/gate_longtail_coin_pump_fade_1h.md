## 公式
- 合格：t 与 t−24 均有收盘；合约上线满 720h；过去 24 根里 ≥20 根有成交。
- r24 = ln(C_t / C_{t−24})。暴涨事件：r24 首次 ≥ ln(1+X)；暴跌事件：r24 首次 ≤ ln(1−X)。
- 第 t+1 根 Gate 开盘吃单入场，持有 H 根后开盘离场（合约提前停牌则用最后收盘）；fade = 做空暴涨 / 做多暴跌，follow 反之。固定灾难止损：逆向 40%（用持仓期内 1h 高 / 低价触发，按止损价成交），未调参。同合约同格不重叠。
- 每笔净收益 = 方向 × 价格收益 − 方向 × 持仓期内官方资金费 − 2 × 费率；费率实费 5.1 bps / 边、压力 15.1 bps / 边，另报「压力 + 50 bps / 边流动性」口径。组合口径：每笔 5% 权益，按离场日汇总。
- 切分：deep 未见 2021-10-01 → 2024-10-21；test → 2026-03-05；post → 2026-11-27。new8 不适用（宇宙本身排除了 d8 / new8）。

- 平移安慰剂（先验 post）：−168h −99.4、+168h −43.4、−72h −255.4、+72h +2.7；事件比安慰剂好，但先验自身 deep 为负、post t 只有 0.6。
- 邻域（post）：X 0.25 +43.6、X 0.40 +50.3、H 12 +27.7、H 36 +58.2，都为正但 t ≤ 1.2，deep 全部为负。
- 结构性发现：做空被拉盘的长尾币，**中位数**每笔约 +390 ~ +810 bps、胜率约 61 ~ 63%，但均值被少数继续暴涨的尾部（触发 40% 止损）吃掉；被拉盘币的资金费常为负，做空方 24h 平均多付约 25 ~ 70 bps（各段 只算价格 − 含资金费 之差）；再加真实长尾点差 / 滑点，边际归零或为负。
- 非先验 dump fade（暴跌后做多）deep / test 极大（X0.30 H48 test +1,199 bps，t 14），但 post 只有 +21（剔除前 1% 后 −163），中位为负，且大部分来自少数崩盘币反抽（CEL、AIA 等），不可交易。

## 结论
**否决**，不实现、不进观察名单、不改默认、不动纸面实例，无代码改动。先验 deep 未见段为负，回退 test 为负；post 正值来自价格中位数，但资金费与长尾流动性成本足以抵消；OKX 子集 post ≈ 0，deep −229。

## 勿重测（never retest by…）
不要通过改 X / H / 止损幅度 / 上线天数 / 成交门槛 / fade↔follow / 入场延迟，改用 r6 / r12 / r48 / r72 或 z 化收益、成交量确认、资金费过滤、BTC 对冲，换 OKX / Binance / Bybit 长尾宇宙，或改用 15m / 4h 周期来重测「单个长尾币自身暴涨 / 暴跌后交易该币」本族；暴跌后做多（dump fade）的 deep / test 大值也不得以 post 之后的新切分重新挑选。
