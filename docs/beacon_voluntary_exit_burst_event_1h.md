- 查重：docs / `output/research_*.csv` / 记忆检索 beacon / slashing / 罚没 / exit queue / validator / staking / lido / eigenlayer。已否决且不同的族：`eth_beacon_staking_gate_4h`（ValidatorQueue / beaconcha.in 日度质押存量与进出**排队水位**、Beaconscan 日度存款，作 4h 闸门）、`eth_validator_withdrawal_burst_event_1h`（EIP-4895 执行层提款，退出后数天到数周才支付）、`eth_deposit_contract_burst_event_1h`、漏槽、`lido_wq_burst_event_1h`、Lido APR、stETH 折价、EigenLayer StrategyManager。文档中没有信标块里 SignedVoluntaryExit（退出**意向**被打包的那一刻）或罚没操作的 1h 事件族。

- 数据（官方、不编造、不回补）：ethPandaOps Xatu 公开 parquet `canonical_beacon_block_voluntary_exit` 与 `canonical_beacon_block_{attester,proposer}_slashing`（即标准信标节点提供的同一批 canonical 信标块操作）。退出：2020-12-01 → 2026-11-21 共 2,182/2,182 个日文件齐全，1,395,154 个验证者退出（按验证者去重、取首次打包），时间 = 打包块官方 `slot_start_date_time` UTC。罚没：两表 3,705 个文件 + 659 个 404（=当日无该操作），594 个被罚没验证者（攻击者罚没 = 两份证明索引交集；提议者罚没 = 提议者），195 个小时，最后一次 2026-08-21 02:00Z。核验：公共标准信标 API（publicnode `/eth/v1/beacon/states/head/validators`）594/594 个罚没验证者 `slashed=true`；随机 300 个退出验证者 300/300 已设 `exit_epoch`。官方 1h 序列 52,356 小时，0 缺口；评分从 Capella 2023-04-12 22:00Z 开始（之前退出不可提取、几乎为 0：2021 年 17 个、2022 年 848 个；之前记 NaN 不记 0），评分段 31,658 小时，零退出小时 5,912，单小时最大 4,720（2024-01-04 20:00Z）。未含：Pectra（2025-05-07）后 EIP-7002 执行层触发退出与余额驱逐（不在本序列、未预注册，看结果后不得加入）。
- 滞后：已收盘信号小时之后下一根 1h 永续开盘入场（信标块几秒内公开；Xatu 只是归档）。
- 公式（预注册 144 格，`scratch/beaconexit1h/PRE_REGISTER.json`，算 PnL 前锁定）：`log_n_vexit = log1p(n_vexit)`、`raw_n_vexit = n_vexit`；z 相对过去 168h（截至 t−1，最少 84h）；L=1/4/8，`z_L = (sum_L x − Lμ)/(σ√L)`；k=3/4/5；burst / twosided；mom / contra；H=24/48。8 币等权篮子，OKX d8 + 未调参 new8 + Gate d8，官方 1h 永续 K 线 + 官方资金费，taker 5.1 bps×2（压力 15.1），±720h 平移安慰剂。先验（锁定）：退出突发 = 解质押卖压 / 运营方事故 / 风险规避 → 做空篮子，先验格 `log_n_vexit_L4_k3_burst_contra_H24`，回退 `log_n_vexit_L1_k3_burst_contra_H48`。分段：train（深度未见）2023-04-12→2024-10-21，test →2026-03-05，post →2026-11-22，Gate 窗口 2025-09-28 起。
