- 结论：**观察（未达强观察门槛），不实现、不改默认、无策略代码改动**。先验在 Gate 三段 + OKX 归档小样本同号、每笔边际结构上大（数百 bps，费用不敏感），但：(1) 只有 30 个 Gate 事件、post 9 个、post t≈1、月份 4/9；(2) OKX 无法用官方数据充分复核（post n=2，+17）；(3) 对入场延迟敏感，且这些小币在公告后点差 / 滑点远大于 5.1 bps taker 假设，容量很小；(4) +168h 安慰剂同样为正。已起实时官方记录器积累前向证据：`scratch/bnbannounce1h/record.py`（每 5 分钟拉 catalog 161 / 48，新下架公告即记录 Gate 永续最新价，写 `scratch/bnbannounce1h/live/binance_announcements_live.csv`，不下单）。待前向 ≥10 个新 spot_delist 事件且同号、并用逐笔 / 15m 核实真实可成交价后再考虑做成默认关闭的可选策略。勿以改 H / 侧 / 对冲、改入场延迟、换公告类别（Monitoring Tag、Margin 下架、交易对移除、Alpha 移除）或换别家交易所公告（OKX / Upbit / Coinbase）的方式在现有历史上重测本族。
