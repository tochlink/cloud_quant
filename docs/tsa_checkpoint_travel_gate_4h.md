# 美国 TSA 官方机场安检日通过人数同比 → 4h 默认书入场闸门（先验否决；非先验不入观察）

## 长线新族：TSA checkpoint throughput 同比（yoy7 / yoy28 / yoy91）作为 4h 默认书入场闸门（2026-11-22 ~02:25 PST，研究，不改默认；否决）

- 查重：`docs/STRATEGY_FORMULAS.md`、`docs/*.md`、scratch、`output/research_*.csv`（1,160+ 个）检索 TSA / checkpoint / air travel / passenger / 出行 0 条，记忆中也无 TSA / 出行族。不是已否决的 GDPNow、Empire / Philly 制造业调查、初请失业金、CPI 通胀体制、消费者情绪等（那些是调查 / 模型宏观数据）；本族是每天的实物消费出行计数。
- 机制：TSA 每日安检人数 = 美国消费者可选支出 / 出行的实时代理。出行强（同比上升）= 消费 risk-on → 允许开多；出行弱 / 减速 = risk-off → 拦新多。只拦新开仓，已有持仓、止损、离场不变。默认 4h 书（#1 双均线 50/150，8 币永续）。
- 数据（只用官方，不编造、不回补）：tsa.gov `travel/passenger-volumes`（含 /2019 … /2025 年度页）官方 HTML 表，2019-01-01 → 2026-11-19 共 2,880 天，0 个日历缺口，无填充。存 `output/tsa_checkpoint_official_daily.csv`（不入库），原始页 `scratch/tsa4h/raw/`。
- 滞后：D 日数据 D+5 00:00 UTC 起才用（TSA 下一个工作日发布，周末 / 假日批量在周一 / 周二发布；D+5 覆盖周一假日周的周五数据），前向填充到 4h K 线。
- 公式（看 PnL 前写入 `scratch/tsa4h/PRE_REGISTER.json` 锁定，2026-11-22 02:07 PST，共 120 格）：
  - `yoyW = log(sum_W(D) / sum_W(D−364))`，W = 7 / 28 / 91（364 天 = 星期对齐）。
  - 形式：`lvl`：yoy > 0；`trend`：yoy > SMA(n)，n 28 / 91；`chg`：yoy − yoy.shift(n) > 0，n 28 / 91；`z`：(yoy − SMA365) / STD365 > k，k 0 / 0.5 / 1.0。flag = 1 = 出行强 / 上升。
  - 侧：long_off（flag=0 拦新多）/ short_off（flag=1 拦新空）/ both（两者）/ contra_both（flag=1 拦新多、flag=0 拦新空）/ cap_long_off（flag=1 拦新多）。3 × 8 × 5 = 120 格 + 同脚本基线。
  - 经济先验（锁定）：long_off 与 both（精确匹配，contra_both / cap_long_off 不算）；安慰剂锚 = 按 9 切片 Sharpe 胜数最好的先验格，否则回退 `yoy28_trend_n91_long_off`。实际锚：`yoy7_chg_n28_both`。
  - 新冠说明：2021–2022 的同比被 2020–2021 封控基数扭曲，z365 预热含 2021 下半年；未改、未剔除（看结果后不调）。
- 验证：OKX d8（2023-02→）/ Gate d8（2022-07→）/ OKX d7_noBNB（2022-04→）官方永续 + 现货 4h，官方资金费；真实费率（永续 taker 5.1 bps、maker 2）与压力费率（永续 taker 15.1 bps）；深未见 →2024-10-21、调参段 →2026-03-05、post →2026-11-14；安慰剂日历平移 +7 / −7 / +14 / −14 / +180 / −120 / +365 / −119 天；邻域；new8 未调参币（OKX + Gate 最近 4500 根 4h）。
- 默认门槛：深未见 + 调参段 Sharpe 两所都胜，且 post（2026-03-05 后）两所 ≥ 6/9 月更好，并有安慰剂 + 邻域支持。
