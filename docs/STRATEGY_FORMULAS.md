# 策略公式与参数记录（dual_ma_trend_4h_v1）

本文件是策略逻辑、公式、参数的**持续记录**，每次 7×24 打磨新增或测试一条规则都在这里补一行。
所有研究只用 OKX / Gate.io 官方公共历史 K 线（现货 + USDT 永续，各用各的价格），不使用模拟数据，不拿现货代替永续。
研究结果表在 `output/research_*.csv`（本地生成，不进 git）。

## 一、当前默认规则（全部已生效）

| 模块 | 公式 | 参数（默认） | 含义 |
|---|---|---|---|
| 均线信号 | `raw_t = sign(SMA_fast_t − SMA_slow_t)` | `fast_ma=20`，`slow_ma=60` | +1 做多（现货），−1 做空（永续），0 空仓 |
| 信号确认 | `sig_t = raw_t`，若 `raw_t = raw_{t−1} = … = raw_{t−k+1}`，否则 0 | `confirm_bars=2` | 交叉后需连续 k 根已收盘 K 线同向 |
| 现货/永续合成 | 现货 +1 且永续 ≠ −1 → +1；永续 −1 且现货 ≠ +1 → −1；其余 0 | — | 两个市场各算各的信号，冲突时空仓 |
| 趋势入场闸门 | 做多需 `close_{t−1} > SMA_N`，做空需 `close_{t−1} < SMA_N` | `trend_ma=100`（0=关） | 只拦新开仓，不平已有仓 |
| ATR | `TR = max(H−L, |H−C_{prev}|, |L−C_{prev}|)`，`ATR = SMA(TR, n)` | `atr_period=14` | 波动尺度 |
| 仓位 | `名义 = 权益 × r ÷ (m × ATR / 价格)`，再 ≤ 权益 × w | `r=5%`，`m=2`，`w=20%` | 每笔最多亏 r 的权益 |
| 总敞口 | 同一根多笔新仓按剩余额度 `权益 × G − 已有敞口` 等比缩放 | `G=1.0` | 不加杠杆 |
| 止损 | 多：`入场价 − m×ATR`；空：`入场价 + m×ATR`（ATR 取入场前一根） | `atr_stop_mult=2.0` | 止损后锁定，直到信号方向改变 |
| 空头熔断 | 影子「只做空」账本，若最近 N 根内已平仓空单合计 PnL < 0，则暂停新开空；影子账本固定用标准仓位口径（起始 1000 USDT、单笔风险 5%、单币 20%、总敞口 1 倍），与账户实际仓位上限无关（2026-11-10 起） | `short_breaker_bars=60`（0=关） | 只用之前已平仓数据，无前视；默认参数下结果不变 |
| 信号反转（翻仓） | 持仓方向 ≠ 上一根收盘信号 → 本根开盘平仓（原因「信号反转」/「信号转空仓」）；同一根的入场步骤里，若新信号非 0 且通过趋势闸门、空头熔断、止损/止盈锁定，再按新方向开仓（多→现货、空→永续），两条腿各按所在市场收 taker 费 | — | 回测、模拟盘引擎一致；默认 `confirm_bars=2` 时交叉后中间会先出现 1 根 0，所以实际是「先平仓，下一根再开反向」，只有 `confirm_bars=1` 才会同一根直接翻仓 |
| 固定止盈（可选，默认关） | 目标价 `TP = 入场价 ± k × R`，`R = |入场价 − 初始止损| = m × ATR`；盘中触及即全部平仓：开盘已越过 TP 按开盘价成交，否则按 TP 价；同一根同时触及止损与 TP 时保守地先算止损；`tp_reentry=false` 时止盈后与止损一样锁定到信号改变，`true` 时下一根若信号仍在则按新 ATR 重新开仓 | `tp_r=0`（关；0.5–20）、`tp_reentry=false` | 回测、模拟盘周期与实时止损轮询都按同一公式（`engine.take_profit_hit`）；实盘仍受开关限制 |
| 成交约定 | 第 t 根收盘信号 → 第 t+1 根开盘成交；止损按盘中高低价，跳空按开盘价 | — | 无前视（有单元测试） |
| 手续费（分市场） | 每条市价腿 `费用 = 成交名义 × taker_m`，m = 做多所在的现货 / 做空所在的永续；开、平、加仓各收一次；总敞口缩放预留取 `max(taker_spot, taker_perp)` | `spot_taker_bps=10`、`perp_taker_bps=5.1`（maker 8 / 2 记录备用；旧 `taker_bps` 仅在缺分市场字段时回退） | 2026-11-10 起按 kean 实际账户费率；下一根开盘市价成交按 taker 计 |

## 持仓调仓 rebalance_band（2026-11-11，已设为默认 0.1）

每根新收盘 K 线评估一次（回测：第 i 根开盘；引擎：新 K 线收盘后的第一个周期，记在 `paper_state.rebalance_bar`）。回测和引擎共用同一个计划函数 `qtw/rebalance.py: plan()`。

- 止损距离%：`sp = |现价 − 该仓现有止损| / 现价`（`rebalance_mode="atr"` 时取 `max(sp, atr_stop_mult×ATR/现价)`）
- 单仓目标：`T = min(权益 × max_risk_per_trade / sp, 权益 × max_weight_per_name)`
- 总敞口缩放：`k = min(1, (权益 × max_gross_exposure − 本根新开仓名义) / (ΣT × (1 + taker)))`，目标 = `k × T`
- 触发条件：`|当前名义 − 目标| / 目标 > rebalance_band` 且差额 ≥ 1 USDT；先减后加，加仓受剩余总敞口限制
- 止损价不变（入场时确定，与回测一致）；加仓后入场价取加权均价；减仓按加权入场价结算该部分盈亏
- 手续费：每条调仓腿都按所在市场的 taker 费率收（现货 10 bps，永续 5.1 bps）
- 实盘镜像：减仓用部分数量的 `close_long` 或 `close_short`（永续 reduceOnly），加仓用差额数量的 `open_long` 或 `open_short`；只有三重闸门全开才会真正发单

验证（OKX 和 Gate 官方 4h 历史，2026-03-16 → 2026-11-10，真实费率；12 段里前 6 段选参，后 6 段检验）：

|---|---|---|---|---|---|
| OKX 真实费率 | +31.0% | +50.8%（夏普 1.41→1.94，回撤 −11.9%→−12.1%） | +29.4 | +33.6 | 8 |
| OKX 费率 ×2 | +26.3% | +45.2% | +27.9 | +32.3 | 8 |
| Gate 真实费率 | +31.0% | +49.9% | +29.3 | +33.2 | 8 |
| Gate 费率 ×2 | +26.3% | +43.8% | +27.8 | +31.6 | 7 |

band 取 0.1、0.25、0.5 三档都优于基线，是一片平台，不是孤立峰值。提升主要来自已平仓交易：OKX 已平仓盈亏 156→306 USDT，去掉贡献最大的 3 笔后仍多 +119 USDT。平均总敞口只从 50.5% 升到 54.6%。明细见 `output/research_rebalance_band*.csv`（未推送）。

## 15m 盘中路径判定止损 / 止盈先后（2026-11-10，研究，不改默认）

问题：4h 回测里同一根 K 线同时触及止损价和止盈价时，保守地先算止损。这会不会把固定止盈（`tp_r`）的结果压低？

做法（研究脚本 `scratch/tp15.py` + `scratch/_bt_tp15.py`，未推送，不进引擎）：
- 开盘已越过止盈价 → 按开盘价止盈（与默认相同）
- 同一根 4h 内 `low ≤ 止损价` 且 `high ≥ 止盈价`（多单；空单对称）时，取这根 4h 内 16 根官方 OKX 15m K 线（多单用现货，空单用永续），按时间顺序找第一根触及的：先碰止损 → 按 `min(15m 开盘, 止损价)` 成交；先碰止盈 → 按 `max(15m 开盘, 止盈价)` 成交；同一根 15m 两个都碰 → 仍按止损
- 其余情况与默认回测完全相同（含 rebalance_band 0.1 调仓），费率：现货 taker 10 bps、永续 taker 5.1 bps；压力档 20 / 15.1 bps

| 默认（不止盈） | +50.7% / +11.5 / +38.2 | — | — |
| tp 1.5R 再入场 | +2.3% | +6.4% / −7.1 / +17.9 | 4（4 次都是先到止盈） |

## 流动性 / 波动率的波动率入场闸门（2026-11-10，研究，不改默认）

- 闸门只拦新开仓：信号从 0 或反向翻成新方向时，若闸门不放行就保持空仓；已有持仓、止损、平仓和调仓照旧。

## 替代趋势指标：KAMA / SuperTrend（2026-11-10，研究，不改默认）

- KAMA（Kaufman 自适应均线）：`ER = abs(C_t − C_{t−n}) / Σ_n abs(ΔC)`，`k = (ER × (2/3 − 2/(s+1)) + 2/(s+1))²`，`KAMA_t = KAMA_{t−1} + k × (C_t − KAMA_{t−1})`；(n, s) = (10, 30) / (20, 60)；`C > KAMA × (1 + b)` 做多、`C < KAMA × (1 − b)` 做空、带内保持，b = 0 / 1% / 2%。
- SuperTrend：`ATR_n`（Wilder），上下轨 = (H + L)/2 ± m × ATR，按标准规则收紧轨道，收盘越过上一根轨道翻向；(n, m) = (10, 3) / (14, 3) / (20, 4) / (30, 5)。
- 每种都测「单独作为信号」和「与默认双均线同向才持仓」两版；风控、止损、调仓沿用默认引擎。
- 结果（官方 OKX / Gate 4h，8 个币，2026-03-05 → 11-10，实际费率；h2 = 后 6 段收益之和）：默认 OKX +50.8%（夏普 1.94，回撤 −12.1%，h2 +33.6%），Gate +49.9%（h2 +33.2%）。
  - KAMA 单独：−30.6% ~ +9.8%，平仓笔数 130 ~ 670（默认约 117），b = 0 时被手续费吃光；同向版最好 +21.4%（OKX）/ +19.1%（Gate）。
  - SuperTrend 单独：OKX −0.3% ~ +35.5%（最好 20/4，h2 +24.2%），Gate +7.1% ~ +20.7%，两家不一致；同向版 +26.0% ~ +33.2%，h2 最高 +25.1%，全部低于默认。压力费率结论相同。
- 结论：都不如默认双均线，不改默认，不加入引擎。

## 波动率归一化多周期动量分数（2026-11-10，研究，不改默认）

- 与此前「时间序列动量多回看期投票」的区别：投票版只看各回看期收益的正负号，这里用连续的风险调整分数，并且进出场分开设阈值（滞回）。
- 公式（官方 OKX / Gate 4h）：σ = 最近 60 根 4h 对数收益标准差；s_L = ln(C_t / C_{t−L}) / (σ √L)；S = 平均 s_L。
- 回看期组合：
  - 6 / 18 / 42：1 天、3 天、1 周。
  - 18 / 42 / 126：3 天、1 周、3 周。
  - 6 / 42 / 252：1 天、1 周、6 周。
  - 42 / 126 / 252：1 周、3 周、6 周。

## 持仓情绪：多空账户比 / 精英持仓多空比闸门（2026-11-10，研究，不改默认）

## Parabolic SAR 趋势族（2026-11-10，研究，不改默认）

- 用法：replace（信号 = SAR 方向）；agree（双均线信号与 SAR 同向才保留，否则 0）；gate_entry（双均线信号变成新方向时若与 SAR 相反则不开，持仓不受影响）。

## 分层多周期：日线趋势定方向 + 1h 择时入场（2026-11-10，研究，不改默认）

- 数据：OKX / Gate 官方现货 + USDT 永续 K 线，1h 6000 根、日线 420 根、4h 1500 根；共同区间 2026-04-05 ~ 2026-11-10（预热 20 天后），12 段等分，前 6 段 / 后 6 段分开看。
