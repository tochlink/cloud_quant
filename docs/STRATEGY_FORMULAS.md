# 策略公式与参数记录（dual_ma_trend_4h_v1）

本文件是策略逻辑、公式、参数的**持续记录**，每次 7×24 打磨新增或测试一条规则都在这里补一行。
所有研究只用 OKX / Gate.io 官方公共历史 K 线（现货 + USDT 永续，各用各的价格），不使用模拟数据，不拿现货代替永续。
研究结果表在 `output/research_*.csv`（本地生成，不进 git）。

## 一、当前默认规则（全部已生效）

| 模块 | 公式 | 参数（默认） | 含义 |
|---|---|---|---|
| 均线信号 | `raw_t = sign(SMA_fast_t − SMA_slow_t)` | `fast_ma=20`，`slow_ma=60` | +1 做多（现货），−1 做空（永续），0 空仓 |
| 信号确认 | `sig_t = raw_t`，若 `raw_t = raw_{t−1} = … = raw_{t−k+1}`，否则 0 | `confirm_bars=2` | 交叉后需连续 k 根已收盘 K 线同向 |
| 现货/永续合成 | 现货 +1 且永续 ≠ −1 → +1；永续 −1 且现货 ≠ +1 → −1；其余 0 | — | 两个市场各算各的信号，冲突时空仓 |
| 趋势入场闸门 | 做多需 `close_{t−1} > SMA_N`，做空需 `close_{t−1} < SMA_N` | `trend_ma=100`（0=关） | 只拦新开仓，不平已有仓 |
| ATR | `TR = max(H−L, |H−C_{prev}|, |L−C_{prev}|)`，`ATR = SMA(TR, n)` | `atr_period=14` | 波动尺度 |
| 仓位 | `名义 = 权益 × r ÷ (m × ATR / 价格)`，再 ≤ 权益 × w | `r=5%`，`m=2`，`w=20%` | 每笔最多亏 r 的权益 |
| 总敞口 | 同一根多笔新仓按剩余额度 `权益 × G − 已有敞口` 等比缩放 | `G=1.0` | 不加杠杆 |
| 止损 | 多：`入场价 − m×ATR`；空：`入场价 + m×ATR`（ATR 取入场前一根） | `atr_stop_mult=2.0` | 止损后锁定，直到信号方向改变 |
| 空头熔断 | 影子「只做空」账本，若最近 N 根内已平仓空单合计 PnL < 0，则暂停新开空 | `short_breaker_bars=60`（0=关） | 只用之前已平仓数据，无前视 |
| 信号反转（翻仓） | 持仓方向 ≠ 上一根收盘信号 → 本根开盘平仓（原因「信号反转」/「信号转空仓」）；同一根的入场步骤里，若新信号非 0 且通过趋势闸门、空头熔断、止损/止盈锁定，再按新方向开仓（多→现货、空→永续），两条腿各按所在市场收 taker 费 | — | 回测、模拟盘引擎一致；默认 `confirm_bars=2` 时交叉后中间会先出现 1 根 0，所以实际是「先平仓，下一根再开反向」，只有 `confirm_bars=1` 才会同一根直接翻仓 |
| 固定止盈（可选，默认关） | 目标价 `TP = 入场价 ± k × R`，`R = |入场价 − 初始止损| = m × ATR`；盘中触及即全部平仓：开盘已越过 TP 按开盘价成交，否则按 TP 价；同一根同时触及止损与 TP 时保守地先算止损；`tp_reentry=false` 时止盈后与止损一样锁定到信号改变，`true` 时下一根若信号仍在则按新 ATR 重新开仓 | `tp_r=0`（关；0.5–20）、`tp_reentry=false` | 回测、模拟盘周期与实时止损轮询都按同一公式（`engine.take_profit_hit`）；实盘仍受开关限制 |
| 成交约定 | 第 t 根收盘信号 → 第 t+1 根开盘成交；止损按盘中高低价，跳空按开盘价 | — | 无前视（有单元测试） |
| 手续费（分市场） | 每条市价腿 `费用 = 成交名义 × taker_m`，m = 做多所在的现货 / 做空所在的永续；开、平、加仓各收一次；总敞口缩放预留取 `max(taker_spot, taker_perp)` | `spot_taker_bps=10`、`perp_taker_bps=5.1`（maker 8 / 2 记录备用；旧 `taker_bps` 仅在缺分市场字段时回退） | 2026-11-10 起按 kean 实际账户费率；下一根开盘市价成交按 taker 计 |

## 持仓调仓 rebalance_band（2026-11-11，已设为默认 0.1）

每根新收盘 K 线评估一次（回测：第 i 根开盘；引擎：新 K 线收盘后的第一个周期，记在 `paper_state.rebalance_bar`）。回测和引擎共用同一个计划函数 `qtw/rebalance.py: plan()`。

- 止损距离%：`sp = |现价 − 该仓现有止损| / 现价`（`rebalance_mode="atr"` 时取 `max(sp, atr_stop_mult×ATR/现价)`）
- 单仓目标：`T = min(权益 × max_risk_per_trade / sp, 权益 × max_weight_per_name)`
- 总敞口缩放：`k = min(1, (权益 × max_gross_exposure − 本根新开仓名义) / (ΣT × (1 + taker)))`，目标 = `k × T`
- 触发条件：`|当前名义 − 目标| / 目标 > rebalance_band` 且差额 ≥ 1 USDT；先减后加，加仓受剩余总敞口限制
- 止损价不变（入场时确定，与回测一致）；加仓后入场价取加权均价；减仓按加权入场价结算该部分盈亏
- 手续费：每条调仓腿都按所在市场的 taker 费率收（现货 10 bps，永续 5.1 bps）
- 实盘镜像：减仓用部分数量的 `close_long` 或 `close_short`（永续 reduceOnly），加仓用差额数量的 `open_long` 或 `open_short`；只有三重闸门全开才会真正发单
