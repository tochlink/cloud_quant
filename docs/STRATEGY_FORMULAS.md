# 策略公式与参数记录（dual_ma_trend_4h_v1）

本文件是策略逻辑、公式、参数的**持续记录**，每次 7×24 打磨新增或测试一条规则都在这里补一行。
所有研究只用 OKX / Gate.io 官方公共历史 K 线（现货 + USDT 永续，各用各的价格），不使用模拟数据，不拿现货代替永续。
研究结果表在 `output/research_*.csv`（本地生成，不进 git）。

## 一、当前默认规则（全部已生效）

| 模块 | 公式 | 参数（默认） | 含义 |
|---|---|---|---|
| 均线信号 | `raw_t = sign(SMA_fast_t − SMA_slow_t)` | `fast_ma=20`，`slow_ma=60` | +1 做多（现货），−1 做空（永续），0 空仓 |
| 信号确认 | `sig_t = raw_t`，若 `raw_t = raw_{t−1} = … = raw_{t−k+1}`，否则 0 | `confirm_bars=2` | 交叉后需连续 k 根已收盘 K 线同向 |
| 现货/永续合成 | 现货 +1 且永续 ≠ −1 → +1；永续 −1 且现货 ≠ +1 → −1；其余 0 | — | 两个市场各算各的信号，冲突时空仓 |
| 趋势入场闸门 | 做多需 `close_{t−1} > SMA_N`，做空需 `close_{t−1} < SMA_N` | `trend_ma=100`（0=关） | 只拦新开仓，不平已有仓 |
| ATR | `TR = max(H−L, |H−C_{prev}|, |L−C_{prev}|)`，`ATR = SMA(TR, n)` | `atr_period=14` | 波动尺度 |
| 仓位 | `名义 = 权益 × r ÷ (m × ATR / 价格)`，再 ≤ 权益 × w | `r=5%`，`m=2`，`w=20%` | 每笔最多亏 r 的权益 |
| 总敞口 | 同一根多笔新仓按剩余额度 `权益 × G − 已有敞口` 等比缩放 | `G=1.0` | 不加杠杆 |
| 止损 | 多：`入场价 − m×ATR`；空：`入场价 + m×ATR`（ATR 取入场前一根） | `atr_stop_mult=2.0` | 止损后锁定，直到信号方向改变 |
| 空头熔断 | 影子「只做空」账本，若最近 N 根内已平仓空单合计 PnL < 0，则暂停新开空 | `short_breaker_bars=60`（0=关） | 只用之前已平仓数据，无前视 |
| 成交约定 | 第 t 根收盘信号 → 第 t+1 根开盘成交；止损按盘中高低价，跳空按开盘价 | taker 4 bps | 无前视（有单元测试） |
