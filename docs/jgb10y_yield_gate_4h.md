# 日本国债（JGB）10 年期收益率 4h 入场闸门（否决）

## 长线新族：日本财务省（MoF）官方 JGB 收益率（10Y 水平 / 10Y−2Y 斜率 / 10Y 20 期变动）→ 4h 默认书入场闸门（日元套息平仓风险）（2026-11-21 ~12:15 PST，研究，不改默认；否决）

- 查重：docs/STRATEGY_FORMULAS.md 中 JGB / 日本国债 / BoJ 只出现在上一轮「下一轮」指针，以及 ECB 决议节的勿重测措辞里（那里说的是 BoJ 决议**事件**，不是收益率水平）。`output/research_*.csv` 没有 jgb / japan / boj 文件，只有已否决的 `research_fx_jpy_cny_trend_gate_4h.csv`（汇率趋势闸门，序列不同）。也不是已否决的美债 DGS10 / 2s10s / Kim-Wright 期限溢价 / Bund 闸门。
- 数据（只用官方，不编造、不回补、不填）：日本财务省官网 `https://www.mof.go.jp/english/policy/jgbs/reference/interest_rate/historical/jgbcme_all.csv`（1974-09-24 → 2026-10-30，13,330 行；10Y 从 1986-07-05 起有值），加上当月文件 `https://www.mof.go.jp/english/policy/jgbs/reference/interest_rate/jgbcme.csv`（2026-11-02 → 2026-11-19，13 行）。两份文件没有重叠日期，合并后共 13,343 行。原表里的 "-" 当缺失处理，不填。研究用 2015-01-05 → 2026-11-19，共 2,902 个官方观测日，没有周末行。有 197 个工作日没有观测（日本节假日），这些日子直接没有数据，不填；最长日历间隔 11 天（2019-05-07 结束，那年黄金周因改元连休 10 天）。日序列存为 `output/jgb10y_official_daily.csv`。最新值（2026-11-19）：10Y 2.870%，2Y 1.853%，斜率 1.017 个百分点。
- 时滞：财务省在 JST 当天傍晚发布。保守起见，观测日 D 的数据从 D+1 00:00 UTC 才开始用，再前向填充到 4h 棒。
- 公式（看 PnL 前写入 `scratch/jgb4h/PRE_REGISTER.json` 锁定，锁定时间 2026-11-21 12:02 PST，sha256 `ba462cdb…5f26f8`，共 120 格）：`jgb10 = 10Y`；`jgbslope = 10Y − 2Y`；`jgb10d20 = 10Y − 20 个官方观测前的 10Y`（跳升 / 变动序列）。形态：trend n∈{30,90,180}（> SMA(n)）、chg n∈{30,90}（n 期变动 > 0）、z252 k∈{1,1.5,2}。五侧：long_off / short_off / both / contra_both / cap_short_off（只拦新开仓，已有同向仓保留）。先验（锁定）：日债收益率高或上升 = 日元套息平仓 risk-off → long_off、both；回退格 jgb10_chg_n30_long_off。
- YCC 退化（每段 flag=1 的时间占比）：日银 YCC 在 2016-09 → 2024-03 把 10Y 钉在 0 附近，2022-04 之后 10Y 一路上行，所以水平类闸门越往后越接近「常开」。jgb10_trend_n180：YCC 段 0.73、deep（2022-04→）0.94、tune 1.00、post 1.00（基本常开）。jgb10_chg_n90 在 post 是 1.00；jgb10_z252gt1 在 tune / post 是 0.95 / 0.93。jgbslope_trend_n90：YCC 段 0.55、deep 0.59、tune 0.73、post 0.65。jgb10d20 的 trend / chg 各段都在 0.35–0.68 之间，没有退化。z252 需要 252 个观测才有值，所以 2015 年段为空。
- 交易数据与评价：官方 OKX / Gate 4h 现货 + 永续（`scratch/deep/*.pkl`，截至 2026-11-14）、官方资金费。三个计划：OKX d8（2023-02-01 起）、Gate d8（2022-07-01 起）、OKX d7_noBNB（2022-04-01 起），各切 deep_unseen（→ 2024-10-21）/ tune_pre（→ 2026-03-05）/ post（→ 2026-11-14），共 9 段，比较日 Sharpe 与同脚本基线。另加未调参 new8（LINK/LTC/DOT/TRX/BCH/ATOM/NEAR/UNI，两所官方 4h 最近 4500 根，2024-11-27 起）。真实费率现货 10 / 永续 5.1 bps，压力费率 20 / 15.1。

- 结果（`output/research_jgb10y_yield_gate_4h.csv` 492 行，含 120 格、基线、先验锚点安慰剂、邻域、压力费，以及非先验最优格的补跑；`block` 列区分。`_new8.csv` 16 行）：
  - **先验锚点 `jgbslope_trend_n90_long_off`（斜率高于 SMA90 时拦新多）6/9**，但这 6 胜是 deep 3 胜加 post 3 个「平手级」小胜。deep 确实更好：OKX +82.42 / 1.29、Gate +42.46 / 0.65、d7 +88.51 / 1.03。可 tune 三家全输：OKX +53.04 / 1.14 vs +85.08 / 1.47，Gate +51.77 / 1.13 vs +84.25 / 1.46，d7 +64.93 / 1.32 vs +92.93 / 1.56。post 几乎就是基线：OKX +60.01 / 2.24、Gate +60.45 / 2.25，月份 2/1、2/1，d7 1/3，**远低于 ≥6/9**。压力费下 post 同样只差 0.1 个点（OKX +56.05 / 2.13 vs +55.94 / 2.12，Gate +56.91 / 2.15 vs +56.78 / 2.15）。未调参 new8 的 2026-03 前两所都略输（OKX 1.04 vs 1.05，Gate 1.02 vs 1.03）；post OKX +4.16 / 0.34 vs +3.26 / 0.28（月份 1/1），Gate +18.18 / 1.10 vs +16.36 / 1.00（2/0）。
  - 先验锚点的安慰剂（平移 ±7 / ±14 / +180 / −120 / +365 / −119 天）最多 4/9（+7 天），低于真实的 6/9。但真实格的边际本身集中在 deep 一段，tune 与 post 并不支持。
  - 先验邻域 n=60/75/105/120/150：最多 3/9。n105–150 的 post 少 9–22 个点（OKX +50.58 / +48.03 / +37.67），n60 / n75 的 post 等于基线 → 邻域不连贯。
  - 其余先验格：jgbslope_chg_n30_long_off 6/9，但 post 闸门完全不触发（月份 0/0，等于基线）；jgb10_z252gt1.5_long_off 6/9，post 只有 +37.76 / +37.90；jgb10_z252gt1.5_both post +11.05。回退格 jgb10_chg_n30_long_off 4/9，post OKX +39.53 / 1.86、Gate +39.78 / 1.87，月份 1/3（new8 的 2026-03 前 1.47 / 1.45 vs 1.05 / 1.03 明显更好，但 post 不变，主书 tune / post 也输）。
  - 非先验最好的是 `jgb10d20_trend_n180_short_off`（20 期变动低于其 SMA180 时拦新空），9/9：OKX post +62.64 / 2.33（月份 3/3），Gate +63.50 / 2.36（4/2），d7 +54.02 / 2.23（4/2）；deep 0.82 / 0.14 / 0.84，tune 1.72 / 1.69 / 1.76；压力费 OKX +58.86 / 2.22、Gate +60.03 / 2.26。不过：post 月份只有 3/3、4/2（< 6/9）；new8 的 2026-03 前两所都输（OKX 1.01 vs 1.05，Gate 0.97 vs 1.03）；**+7 天平移安慰剂同样 9/9，post 更高（OKX +65.31、Gate +65.93，三家月份都是 6/2）**，+365 天 post +67.05 / +67.83；邻域 n120 / 150 / 210 / 240 / 270 在 OKX d8 与 Gate d8 的 deep 全输（0.62–0.68 vs 0.71，−0.11–0.03 vs 0.09），只有 n180 单点成立。这是看结果后挑出的反向侧，不采用。
- 结论：**否决**。不实现、不进观察名单、不改默认、不动纸面实例，仅文档。日债收益率体制在 tune 与 post-2026-03 上没有增量：先验格的 deep 优势在 tune 段被反转，post 等于基线，月份远低于 6/9；YCC 结束后水平类闸门近乎常开（信息量趋近 0）；非先验 9/9 被平移安慰剂追平或超过，邻域断裂。勿以同一机制换 n / k / 方向，或换期限（1Y–40Y、2s30s、5s30s、超长端 20Y / 30Y / 40Y）、换变动窗口（d5 / d10 / d40）、换 BoJ 政策利率 / YCC 区间 / 国债购买量、换日美利差（JGB10 − UST10）再测。
