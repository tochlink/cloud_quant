# BTC 长周期价格估值带（幂律残差 / Mayer 倍数 / 200 周均线倍数）4h 入场闸门（否决）

## 长线新族：BTC 长周期价格估值带 → 4h 默认书入场闸门（2026-11-21 ~15:25–15:40 PST，研究，不改默认；否决）

- 查重：docs/STRATEGY_FORMULAS.md、docs/*.md、`output/research_*.csv`（1,115 个）、scratch 与记忆检索 power law / 幂律 / Mayer / 梅耶 / 200-week / 200 周 / pi cycle / 对数回归 / valuation 均无测试条目。不同于已否决的 MVRV / 已实现价格估值（链上成本基础，"不再重测 MVRV / 已实现价格估值族"）、Puell、BTC 体制线（btc_regime_ma=1200 根 4h ≈ 200 日均线的**穿越**，本族只用远离 1 的极端倍数 0.8/1.2/1.5/2.4 与 200 周 / 幂律）、反追逐延伸（单币短周期 ATR 延伸）、整数关口。原定"8 币平均两两相关 4h 闸门"与已测相关族重复，未跑。
- 机制（看 PnL 前锁定的唯一先验）：价格远高于长期公允值 = 周期末端泡沫 → **拦新开多** `pl_gt0_long_off`；回退：跌破 200 周均线（历史投降底部区）→ **拦新开空** `m200w_gt1_short_off`。只拦新开仓，持仓、止损、退出不变。
- 数据（仅官方，不编造、不补缺）：OKX 官方 BTC-USDT 现货日线 `/api/v5/market/history-candles?bar=1Dutc`，2018-01-11 → 2026-11-20 共 3,236 个已确认日、0 缺口；与 OKX 官方 4h 现货收盘逐日核对 2,084 天，最大相对差 0。存 `output/btc_price_valuation_official_daily.csv`（sha256 cc8b5b2e…4c73，不入库）。现货只作为信号输入，交易仍是官方永续。
- 公式（UTC 日 D 收盘价 P，D+1 00:00 UTC 起用，ffill 到 4h）：
  - `pl = log10(P / 10^(−17.01593313 + 5.84509376 · log10(d)))`，d = 距 2009-01-03 创世块天数（固定外部幂律模型，未在本数据上拟合）；
  - `mm = P / SMA200d(P)`（Mayer 倍数）；`m200w = P / SMA1400d(P)`（200 周均线倍数，2021-11-10 起）。
  - flag = 序列 > k：pl k ∈ {−0.3, −0.15, 0, 0.15}；mm k ∈ {0.8, 1.2, 1.5, 2.4}；m200w k ∈ {1.0, 1.5, 2.0, 3.0}。侧：long_off（flag=1 不开新多）/ short_off（flag=0 不开新空）/ both / contra_both。
- 格子：3 序列 × 4 阈值 × 4 侧 = **48 格** + 同脚本基线（= 生产回测默认参数）；`scratch/btcval4h/PRE_REGISTER.csv` 在任何 PnL 前锁定（sha256 174dbf97…39e1a）。harness 同 ustvol4h / epu4h：官方 OKX d8（2023-02→）/ Gate d8（2022-07→）/ OKX d7_noBNB（2022-04→）4h；deep unseen → 2024-10-21，tune → 2026-03-05，post → 2026-11-14；真实费（永续 maker 2 / taker 5.1 bps），压力 spot 20 / perp 15.1；官方资金费；安慰剂平移 ±7/±14/+180/−120/+365/−119 天；阈值邻域；未调参 new8。

  - 先验 `pl_gt0_long_off`：**3/9**——deep 与 post 完全等于基线（从不触发，月份 0/0），只有 tune 小赢（OKX +87.52%、Gate +86.21%、d7 +95.52%）；安慰剂 −14d tune 更好（+91.80%）；new8 post 不变；邻域 pl 0.05/0.1/0.2 全 0/9。先验不成立。

- 结论：**否决**，不实现、不进观察名单、不加模拟盘、不改默认，无代码改动。BTC 长周期估值带对默认书新开仓没有稳定增量：幂律先验在 deep / post 空转；200 周均线回退的 deep 提升被平移安慰剂追平，post 月份不足，邻域断裂。勿以同一机制换阈值 / 侧 / 模型系数（Santostasi / Burger / 其他幂律或对数回归通道）、换均线长度（Mayer 的 100/200/365 日、200 周 / 4 年）、换 Pi Cycle / 2 年 MA 倍数 / 彩虹图 / 对数增长曲线、换 ETH 或篮子价格估值再测。
