# 长线新族：OKX 官方 BTC / ETH 币借贷利率（杠杆做空需求）与 USDT ÷ 币借贷比（多空杠杆需求比）→ 4h 默认书入场闸门（2026-11-27 ~13:48–14:20 PST，研究，不改默认；否决）

## 查重
- `docs/STRATEGY_FORMULAS.md`、`docs/*.md`（157 个）、`output/research_*.csv`（1,333 个）、scratch 目录检索 lending / 借贷 / 借币 / ccy=BTC / BTC 借贷 / short demand / borrow：唯一先例是 **OKX USDT 借贷利率闸门**（2026-11-14 弱观察，纸面 `usdt_lending_gate`）= 计价币借贷 = **多头杠杆需求**；其勿重测只覆盖 USDT 序列的 chg / short 侧变体。从未用过 **BTC / ETH 币借贷利率**（借币 = 现货杠杆做空的融资成本 = 做空需求的官方价格），也没用过 USDT ÷ 币的多空杠杆需求比。
- 不同于资金费（永续）、基差、OI、多空账户比、Bitfinex 保证金多空持仓（他所持仓量，不是利率）、Aave 链上借款年化。

## 数据（只用官方，不编造、不插值、不回补）
- OKX 官方公共接口 `GET /api/v5/finance/savings/lending-rate-history?ccy={BTC,ETH,USDT}`，逐小时 `lendingRate`（年化），2021-12-14 09:00 → 2026-11-27 21:00 UTC，每币 43,420 条，各 1 处小时缺口；日值 = UTC 日内小时均值（该日 ≥ 20 个小时点才有值，否则 NaN），1,809 个日历日 0 缺日、2 个 NaN 日。存 `output/okx_coin_lending_official_daily.csv`（不入库）。
- **数据结构性事实（看 PnL 前已在 PRE_REGISTER 之后、跑前发现，未改网格）**：BTC 借贷利率 2026-04 前 99.7% 的日子钉在 1% 下限（ETH 67%、USDT 22%）；约 2026-04-08 起 OKX 取消 1% 下限，BTC 跌到 0.01–0.2%、ETH 0.3–0.8%。因此 btc 序列在深未见 / 调参段几乎无信息，ls 序列在 post 段被下限取消结构性抬高。
- 可用时刻：D 日值 D+1 01:00 UTC 才用，前向填充到 4h K 线。交易数据：官方 OKX / Gate 4h（scratch/deep，回测到 2026-11-14），官方资金费；真实费（永续 taker 5.1 bps / maker 2 bps）+ 压力费（永续 taker 15.1 bps、现货 20 bps）。

## 公式与预注册
- 序列：`btc` = BTC 日均借贷利率；`eth` = ETH 日均借贷利率；`ls = ln(USDT) − ½(ln BTC + ln ETH)`（多头杠杆需求 ÷ 做空需求）。
- 形式：trend = 值 > SMA(n)，n ∈ {30, 90, 180}；chg = n 日变化 > 0，n ∈ {30, 90}；z365 = (值 − SMA365) / STD365 > k，k ∈ {1, 1.5, 2}。
- 侧：long_off（flag=1 拦新多）、short_off（flag=0 拦新空）、both、contra_both（flag=0 拦多、flag=1 拦空）、cap_short_off（flag=1 拦新空）。只拦新开 / 反手，已有同向仓、止损、离场不变；NaN 不拦。
- 3 × 8 × 5 = 120 格 + 同脚本基线（S.DEFAULTS 双均线 50/150 4h 8 币）。经济先验（看结果前锁定）：btc / eth flag=1 = 空头拥挤 → cap_short_off；ls flag=1 = 多头拥挤 → long_off。
- 先验格 `btc_trend_n30_cap_short_off`，回退 `ls_trend_n90_long_off`。PRE_REGISTER.json sha256 `6c929e3b2a62c60b60318211f6c5fb8255fd345791d460e69d688aa9f8a59b08`（2026-11-27 13:48 PST，任何 PnL 之前锁定）。
- 评分：9 个 Sharpe 切片（OKX d8 2023-02-01 起、Gate d8 2022-07-01 起、OKX d7 去 BNB 2022-04-01 起 × 深未见 <2024-10-21 / 调参前段 / post ≥2026-03-05）。

## 结论
**否决**，不改默认、不实现、不加纸面实例、无代码改动。先验 / 回退被安慰剂击败；BTC 借币利率在 2026-04 前钉在 OKX 1% 下限，没有信息；唯一 8/9 的非先验格 post 优势与 OKX 2026-04 取消下限的结构跳变重合，+7d 平移安慰剂更好，邻域 z≥1.75 崩塌，new8 未调币 pre 段大幅落后。
