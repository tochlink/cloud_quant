# Kim-Wright 国债期限溢价 4h 入场闸门（否决）

## 长线新族：美联储理事会 Kim-Wright 三因子模型国债期限溢价（10Y TP / TP10−TP2 斜率 / 10Y 风险中性收益率）→ 4h 默认书入场闸门（2026-11-20 ~22:35 PST，研究，不改默认；否决）

- 查重：文档 / `output/research_*.csv`（1,025 个）/ 记忆中无 term premium / 期限溢价 / Kim-Wright / THREEFYTP / ACM 条目。不是已否决的 DGS10 / 2s10s / WTI 闸门、TIPS 实际利率 / 美元 / VIX 闸门、联储净流动性、NFCI / STLFSI、信用利差、SOFR−IORB、M2、通胀体制。本轮先考察了交易所**保险基金**余额（未测过），但 Gate `/futures/usdt/insurance` 只给 31 天、OKX `/public/insurance-fund` 只回溯约 3 个月，没有未见历史，放弃。结构类（出场 / 仓位 / 组合构建）候选逐一检索均已测过（追踪止损、时间止损、相位分散、净敞口上限、持仓数上限、入场失败离场、资金费调整信号等），所以本轮选未测的官方序列。
- 数据（只用官方，不编造、不回补）：美联储理事会官网 `federalreserve.gov/data/yield-curve-tables/feds200533.csv`（Kim & Wright FEDS 2005-33 模型，理事会员工研究产品，非正式统计发布、可能修订），1990-01-02 → 2026-11-13，9,203 个观测日；与 FRED 镜像 THREEFYTP10 / THREEFYTP2 / THREEFY10 逐日逐值完全一致（差 0）。研究用 2015-01-02 起 2,968 个观测（缺的节假日直接没有，不填）。日序列 `output/kim_wright_term_premium_official_daily.csv`。
- 时滞：理事会每周批量更新（2026-11-20 时最新观测 2026-11-13）→ 保守按观测日 D + 10 天 00:00 UTC 才可用，再前向填充到 4h 棒。
- 公式（看 PnL 前写入 `scratch/kwtp4h/PRE_REGISTER.json` 锁定，120 格）：`tp10 = THREEFYTP10`；`tpslope = THREEFYTP10 − THREEFYTP2`；`rn10 = THREEFY10 − THREEFYTP10`（风险中性 / 预期短端路径部分）。形态 trend n∈{30,90,180}（> SMA(n)）、chg n∈{30,90}（n 期变动 > 0）、z252 k∈{1,1.5,2}；五侧 long_off / short_off / both / contra_both / cap_short_off（只拦新开仓，已有同向仓保留）。先验（锁定）：期限溢价高 / 上升 = risk-off → long_off、both；回退格 tp10_trend_n90_long_off。
- 交易数据与评价：官方 OKX / Gate 4h 现货 + 永续（`scratch/deep/*.pkl`）、官方资金费；OKX d8（2023-02-01 起）、Gate d8（2022-07-01 起）、OKX d7_noBNB（2022-04-01 起）× deep_unseen（→ 2024-10-21）/ tune_pre（→ 2026-03-05）/ post（→ 2026-11-14）= 9 段日 Sharpe 对同脚本基线；另加未调参 new8（LINK/LTC/DOT/TRX/BCH/ATOM/NEAR/UNI，两所官方 4h 最近 4500 根，2024-11-26 起；OKX 官方深资金费、Gate 官方资金费）；真实费率现货 10 / 永续 5.1 bps，压力 20 / 15.1。
- 同脚本基线：OKX d8 deep +35.14% / Sharpe 0.71，tune +85.08 / 1.47，post +59.90 / 2.23；Gate d8 deep −3.63 / 0.09，tune +84.25 / 1.46，post +60.32 / 2.25；OKX d7 deep +54.92 / 0.75，tune +92.93 / 1.56，post +50.76 / 2.10。
- 结果（CSV `output/research_kim_wright_term_premium_gate_4h.csv`，519 行：120 格 + 基线、安慰剂、邻域、压力费、new8；`block` 列区分）：
  - **先验最好 `tp10_z252gt2_both` 只有 5/9**（z>2 拦新多，否则拦新空）。post 确实更好：OKX d8 +65.98 / 2.52（月份 6/2）、Gate d8 +66.31 / 2.54（6/3）、d7 +56.13 / 2.40（4/4），压力费同向（OKX +62.93 / 2.44 vs +55.94 / 2.12，Gate +63.27 / 2.45 vs +56.78 / 2.15）。但**未见历史被打穿**：deep OKX +7.36 / 0.30 vs +35.14 / 0.71，Gate −12.48 / −0.19 vs −3.63 / 0.09；tune 收益 +61.0 / +61.6 vs +85.1 / +84.3；未调参 new8 2026-03 前 OKX +9.69 / 0.41 vs +49.57 / 1.04、Gate +9.71 / 0.41 vs +46.93 / 1.02（post OKX 0.24 vs 0.28、Gate 1.06 vs 1.00，月份 4/5）。原因：z>2 在 deep 只占 3.5%、post 占 38%，「both」在 2026-03 前基本等于「禁空」，post 收益来自本轮熊段的偶然体制，不是期限溢价信息。
  - 安慰剂（同锚点平移 ±7 / ±14 / +180 / −120 / +365 / −119 天）：+14 天 7/9、+7 天 6/9 都高于真实 5/9；+7 天 post 更高（OKX +68.14、Gate +68.05，月份 6/6）→ 信号不特异。
  - 邻域 k：1.75 崩（OKX post +46.96，deep −21.81 / −0.64），2.25 / 2.5 post 更高（+71.9 / +73.8）但 OKX d8 与 Gate d8 deep 仍输（0.38 / −0.10 vs 0.71 / 0.09）；1.5 / 1.0 post 只有 +42 / +39。
  - 其余先验格：rn10_trend_n180_long_off、rn10_chg_n90_long_off 5/9 但 post −20 点（+39.53 vs +59.90）；回退 tp10_trend_n90_long_off post +39.53，失败。
  - 非先验最好 `tp10_trend_n90_short_off`（TP 低于 SMA90 拦新空）7/9：tune 更好（OKX 1.71 vs 1.47、Gate 1.77 vs 1.46），但 OKX d8 deep 打平 0.71、Gate deep 0.04 < 0.09；post 只差 1 个月（OKX +61.14 vs +59.90，Gate +61.55 vs +60.32，月份 1/0，因 post 94% 时间 TP 高于均线、闸门空转）；new8 pre OKX 1.08 vs 1.04、Gate 1.06 vs 1.02，post 月份 1/0；安慰剂 ±7 天同样 7/9；邻域 n60–150 6–8/9 但 post 都只差 1 个月。看结果后的反向侧，不采用。
- 结论：**否决**，不实现、不进观察名单、不改默认，仅文档。期限溢价体制在未见历史上没有增量；post 的好看来自 2026 年 TP 抬升期恰逢加密下跌的单段巧合，平移安慰剂同样能打出。勿以同一机制换 n / k / 方向，或换期限（TP1–TP10、远期期限溢价 THREEFFTP）、换 ACM（纽约联储）期限溢价、换风险中性收益率 / 拟合收益率再测。
- 方法备注：沿用 SOFR 脚本时发现 `is_econ` 用后缀匹配，把 `contra_both` 也当成先验侧（安慰剂锚点被错选为非先验 tpslope_chg_n90_contra_both）；本轮用 `scratch/kwtp4h/supp.py` 对正确先验锚点补跑了安慰剂 / 压力费，结论以补跑为准。此前 SOFR / ERC-4337 / Arbitrum 等同模板研究若先验侧含 both，锚点可能同样受影响（结论均为否决，不改变默认）。
