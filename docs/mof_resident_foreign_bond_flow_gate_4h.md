# 长线：日本财务省周度「居民净买外国中长期债券」资金流趋势 → 默认 4h 书入场闸门（2026-11-22 ~22:05–22:40 PST，强观察 → 纸面 8798，不改默认）

## 查重
- 在 `docs/STRATEGY_FORMULAS.md`、全部 `docs/*.md`、`output/research_*.csv`（199 个 `*_gate_4h*`）里检索 `International Transactions in Securities` / 对外及对内证券 / 対外及び対内証券 / MoF / portfolio flow：只在 3 处被列为「下一轮」（2026-11-22 Aave borrow 节、EDGAR S-1 节），没有 CSV，也没有做完的测试。
- 它和已否决的 JPX 按投资者类别股票买卖不同（JPX 是交易所口径、**非居民**买日股；本族只用**居民**对外这一侧，以免重叠）。也不同于 JGB10y 收益率（价格）、日元 / 人民币汇率趋势、H.4.1 外国官方托管美债（强观察 8794，是外国官方持有美债），以及 TIC / 外汇储备。

## 数据（官方，没有编造，也没有回补）
- 来源：财务省「対外及び対内証券売買契約等の状況（週次・指定報告機関ベース）」`https://www.mof.go.jp/policy/international_policy/reference/itn_transactions_in_securities/week.csv`（Shift-JIS 编码，单位亿日元）。
- 覆盖 2005-01-02 → 2026-11-14 共 1,124 周。财务省每年都不公布跨年那一周，这些周保持空缺、不补；除此之外没有缺口。
- 本地文件：`output/mof_intl_securities_official_weekly.csv`（解析脚本 `scratch/mofsec4h/build.py`）。线上模块用同一来源实时拉取，1,124 周的数值与研究文件逐周一致。
- 发布时滞：周六结束的那一周在下周四 08:50 JST（即周三 23:50 UTC）发布。本研究只在**周末 + 6 天 00:00 UTC（周五）**之后才使用，多留一天来吸收节假日顺延。另做了周末 + 13 天的稳健性检验。
- 修订：用的是当前版本。周度指定机构数据很少修订。

## 公式与预注册（看任何 PnL 之前锁定）
- 锁定文件：`scratch/mofsec4h/PRE_REGISTER.json`，2026-11-22 22:20 PST，sha256 `0d7f32f9…7729`。
- 三个序列：
  - `b4`：居民中长期外债净买的 4 周和；
  - `b13`：同一指标的 13 周和；
  - `e4`：居民外国股票 / 基金净买的 4 周和。
- 八种形式：`lvl0`（> 0）、`chg4` / `chg13`（相对 N 周前上升）、`trend13` / `trend26` / `trend52`（高于 N 周均值）、`z104gt0.5` / `z104gt1`。
- 五种侧：long_off / short_off / both / contra_both / cap_short_off。闸门只拦新开仓。
- 合计 3 × 8 × 5 = 120 格，加同脚本基线（默认 #1 ma_trend MA50/150、8 币、4h，不加闸门）。
- 经济先验：外流为正或在加速 = 日元套息 / 全球风险偏好上升 = risk-on → cap_short_off / contra_both。先验规则是取经济格里最好的一格；回退格是 `b4_lvl0_cap_short_off`。
- 验证：
  - 数据：官方 OKX d8（2023-02 起）、Gate d8（2022-07 起）、OKX d7_noBNB（2022-04 起）的 4h 现货 + 永续，加官方资金费，数据截至 2026-11-14（与近期闸门研究相同，基线可直接对比）。
  - 费率：真实费（永续 maker 2 / taker 5.1 bps），另跑压力费（20 / 15.1 bps）。
  - 分段：深度未见期（→ 2024-10-21）、调参期、post（2026-03-05 → 2026-11-14）。
  - 稳健性：未调参的 new8 篮子（LINK LTC DOT TRX BCH ATOM NEAR UNI）；邻域；±7 / ±14 / +180 / −120 / +365 / −119 天平移安慰剂；周序列 40 次随机循环平移安慰剂。

## 结论
**强观察 → 纸面前向检验，不改默认。**
- 支持：预注册先验 9/9；两所 post 都高约 +11 pp、Sharpe +0.33；压力费下成立；时滞稳健；远距离平移安慰剂和循环平移安慰剂都明显更弱。

## 勿重测
不要靠下面这些办法重测本族：
- 改 sum_n / trend_n / z 阈值 / 侧；
- 在 4 周和、13 周和、外国股票净买之间互换；
- 改用取得额或处分额、总计（含短期债）、非居民买日债 / 日股（与 JPX 重叠）；
- 改用财务省月度「対外証券投資」或按地区、按投资者类别（银行 / 信托 / 寿险）的月度数据；
- 缩短发布时滞；
- 换成 TIC、韩国 / 台湾居民对外证券投资等「本国居民对外证券资金流」同一机制。
这一格只在纸面 8798 上前向观察；只有 post 逐月在两所都达到 ≥ 6/9、并且 new8 不输时，才再讨论改默认。
