## 机制与查重

- 想法：美股上市的加密股（Strategy MSTR、Coinbase COIN）是美股资金对加密风险的代理。rs = ln(股票 / BTC) 在最近 n 个交易日下降
  = 美股资金在减配加密（加密股跑输 BTC）→ risk-off → 暂不新开多。
- 查重：`docs/STRATEGY_FORMULAS.md`、`docs/*.md`、1,169 个 `output/research_*.csv`、记忆中没有 COIN/MSTR 相对 BTC 的相对强弱 / 加密股闸门。
  最接近的已测族：交易所币相对强弱（OKB/GT 对 BTC，加密原生）、美股指数趋势闸门（SPX / Nasdaq 自身趋势）、TradFi 永续趋势 sleeve（交易美股永续本身）、
  美股永续休市跳空（1h）、MSTR 8-K 披露事件（1h）、Coinbase 溢价（现货价差）。本族用的是美股加密股相对 BTC 的强弱变化，不是这些。
- 机制对照（诊断，不是候选）：MSTR 约 1.5–2 倍 BTC beta，rs 可能只是 BTC 动量的伪装 → 加测同日期、同滞后的 BTC 自身 20 交易日变化闸门；
  两者旗标只有 63.2% 一致，BTC 版深未见增益小得多、调参段反而变差（见下表）→ 增益不只是 BTC 动量。

## 公式与参数（PRE_REGISTER.json 于 2026-11-22 04:00 PST 锁定，sha256 1b852f07…a9e，先于任何 PnL）

- 只在交易日 D（且当日 20:00 UTC BTC 收盘存在）计算 rs_D = ln(close_D / BTC20_D)；序列 coin_rs、mstr_rs、ceq_rs（两者均值）。
- 形式 8 种：trend（rs > SMA_n，n = 20 / 50 / 100 交易日）、chg（rs − rs 的 n 个交易日前 > 0，n = 20 / 60）、z（(rs − SMA252) / STD252 > k，k = −0.5 / 0 / 0.5）。
- 侧 5 种（flag = 1 = 加密股相对走强）：long_off（flag = 0 拦新多）、short_off（flag = 1 拦新空）、both、contra_both、cap_long_off。只拦新开仓；持仓、出场、止损不动。
- 3 序列 × 8 形式 × 5 侧 = **120 格** + 同脚本基线。**先验侧** long_off / both（精确匹配）；**回退** `ceq_rs_trend_n50_long_off`。
- 交易：官方 OKX / Gate 永续 + 现货 4h 与官方资金费；OKX d8（2023-02-01 起）、Gate d8（2022-07-01 起）、OKX d7 去 BNB（2022-04-01 起）；
  深未见 → 2024-10-21，调参段 → 2026-03-05，post → 2026-11-14。费用：永续 taker 5.1 / maker 2 bps（压力 15.1），现货 10（压力 20）。
  评分 = 3 组 × 3 段日 Sharpe 胜基线次数（9 分制）。

## 结论

- **默认不变**：改默认要求「未见历史成立 + 2026-03 后两所 ≥ 6/9 个月更好」，post 逐月只有 2 / 1。
- **强观察 → 纸面前向检验**：预注册先验在三组深未见、三组调参段、未调参 new8 两所、压力费下全部更好；120 格唯一 9/9，短窗口邻域稳定；安慰剂最多 6/9；
  比 BTC 自身动量闸门明显更好（不是 BTC 动量伪装）。弱点：post 无信息、长窗口失效、new8 上 +14d 安慰剂同样好。
- 代码（默认关闭）：`qtw/cryptoeq.py`（Nasdaq 官方日收盘缓存 `$QTW_DATA_DIR/nasdaq_<SYM>_daily.csv`，每 2h 刷新；BTC 用同交易所官方 BTCUSDT 现货 4h 的 20:00 UTC 收盘；
  失败 / 数据早于 7 天 / 历史不足 → 不拦并记日志）；`settings`：`cryptoeq_gate_enabled`（false）、`cryptoeq_gate_symbol`（MSTR|COIN，默认 MSTR）、
  `cryptoeq_gate_n`（20，5–120）、`cryptoeq_gate_stale_days`（7，4–30）；环境变量 `QTW_CRYPTOEQ_GATE=1` 强制开启。
  回测把拦截并入借贷 / 托管闸门同一位置（第 i 根开盘入场用第 i−1 根开盘时间上已知的 chg），引擎 `/api/signals` 返回 `cryptoeq_gate`，
  行内 `cryptoeq_chg / cryptoeq_block_long`，被拦时 `state = cryptoeq_wait`。测试 `tests/test_cryptoeq_gate.py`（7 个），全套 492 passed。
- 纸面：`data/paper-cryptoeq/run.sh` → 8795（1000U，币种 / 参数与 8788 默认 #1 相同，只多开加密股闸门；live 强制关闭）。
